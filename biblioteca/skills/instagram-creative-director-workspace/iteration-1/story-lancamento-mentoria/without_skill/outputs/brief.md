# Story 9:16 — Abertura de Vagas: Mentoria de Tráfego Pago

**Tipo de entrega:** Brief detalhado + peça pronta para produção (texto, layout e specs)
**Formato:** Instagram/Facebook Story — 1080 x 1920 px (9:16)
**Objetivo único:** levar o espectador a fazer swipe-up no link de inscrição da mentoria
**CTA principal:** swipe pro link
**Data:** 2026-06-16

> Nota rápida: o "arrasta pra cima" clássico só aparece nativo pra contas com link sticker liberado. Hoje o padrão do Instagram é o **sticker de link** (o "Link" com setinha). Por isso o brief entrega as duas leituras: a copy diz "ARRASTA PRA CIMA / TOCA NO LINK" e o layout posiciona o sticker de link nativo no ponto certo. Use o que sua conta tiver.

## 1. Contexto e premissas

Como não recebi os dados específicos, assumi premissas de mercado para destravar a peça. **Confirme ou ajuste os campos em [colchetes]** antes de publicar — eles mudam a copy final.

- **Produto:** mentoria de tráfego pago (gestão de Meta Ads / Google Ads).
- **Promessa central assumida:** sair do "queimar dinheiro em anúncio" para "campanha que vende com previsibilidade".
- **Público:** dono de negócio / infoprodutor / prestador de serviço que já tentou anunciar e não teve retorno, OU gestor iniciante que quer profissionalizar.
- **Mecanismo de urgência:** vagas limitadas + janela de inscrição curta (gatilho real de lançamento).
- **Campos a preencher:** [NOME DA MENTORIA], [Nº DE VAGAS], [PRAZO/DEADLINE], [PREÇO ou "condição de lançamento"], [BÔNUS], [SEU @], [PROVA: resultado/número].

---

## 2. Estratégia criativa (o porquê de cada decisão)

- **Story vende com 1 ideia por tela.** Um story tem ~5–7s de atenção. A peça é montada para o olho bater na ordem: **TENSÃO → SOLUÇÃO → URGÊNCIA → AÇÃO**.
- **CTA não é enfeite, é o clímax.** Tudo na arte aponta (seta, movimento, cor) para o ponto de swipe na base.
- **Urgência precisa ser verdadeira.** "Vagas abertas" sem escassez real não converte. Por isso o brief exige nº de vagas e deadline — escassez sem número é só barulho.
- **Prova antes de pedir clique.** Um número concreto ([ex.: "R$ 38 mil em vendas no 1º mês de um aluno"]) derruba a objeção "será que funciona pra mim?".

## 4. Layout e composição (grid de segurança 9:16)

Canvas: **1080 x 1920 px**. Respeite as zonas — a UI do Instagram cobre topo e base.

```
┌─────────────────────────────┐  0px
│  ⚠ ZONA MORTA (UI topo)     │  ~250px  → nada importante aqui
├─────────────────────────────┤
│  [BADGE] VAGAS ABERTAS      │  ~320px
│                             │
│  HEADLINE                   │  ~480–820px  (peso visual máximo)
│  EM 2–3 LINHAS              │
│                             │
│  Subhead curta              │  ~900px
│                             │
│  ┌───────────────────────┐ │
│  │ PROVA / número forte  │ │  ~1150px  (card destacado)
│  └───────────────────────┘ │
│                             │
│  [ APENAS X VAGAS · DIA ]   │  ~1380px  (pílula de escassez)
│                             │
│         ↑ ↑ ↑               │  ~1550px  (setas animadas subindo)
│   ARRASTA PRA CIMA          │  ~1620px  (CTA)
│  [ sticker de LINK nativo ] │  ~1700px  ← posicione o link aqui
├─────────────────────────────┤
│  ⚠ ZONA MORTA (UI base)     │  ~1750–1920px → "Enviar mensagem"
└─────────────────────────────┘  1920px
```

**Regras de ouro do layout:**
- Mantenha tudo que é crítico entre **250px e 1750px**.
- O sticker de link nativo deve ficar **logo acima da copy de CTA**, ~1650–1720px, para a seta apontar direto pra ele.
- Headline ocupa o maior peso visual da tela. Se não der pra ler em 1 segundo, está grande demais ou comprido demais.

## 5. Direção de arte

- **Mood:** performance / dinheiro / movimento. Tom confiante, não "fofo".
- **Paleta sugerida** (ajuste à identidade do cliente):
  - Fundo escuro grafite/preto (`#0E0E12`) → faz número e CTA saltarem.
  - Acento de destaque verde-lucro (`#1FE07A`) ou âmbar/ouro (`#FFB020`) para CTA, setas e badge de escassez.
  - Texto branco (`#FFFFFF`) e cinza-claro (`#B8B8C0`) para subhead.
  - **Vermelho/laranja só na escassez** ("fecha dia X") — cria alerta sem poluir.
- **Tipografia:** sans-serif pesada e condensada na headline (ex.: Anton, Archivo Black, Druk). Subhead em peso regular legível (Inter, Söhne, Helvetica).
- **Fundo:** opções, em ordem de impacto:
  1. Gradiente escuro + textura sutil de "gráfico subindo" / linhas de curva ascendente ao fundo (reforça crescimento).
  2. Foto do mentor (você) com overlay escuro 60% e a copy por cima — mais conexão, ótimo para tráfego frio.
  3. Mockup de dashboard de Ads desfocado ao fundo.
- **Hierarquia de cor no CTA:** o botão/pílula de "ARRASTA" é o elemento mais saturado da tela. Nada compete com ele embaixo.

## 6. Movimento (se for story em vídeo/animado — recomendado)

Duração ideal: **6–8 segundos**, em loop.

| Tempo | Elemento | Animação |
|---|---|---|
| 0,0–0,5s | Badge "VAGAS ABERTAS" | fade-in + leve scale |
| 0,3–1,2s | Headline | entra palavra por palavra (stagger), peso de impacto |
| 1,2–2,0s | Subhead | fade-in subindo 20px |
| 2,0–2,8s | Card de prova | "pop" com leve overshoot |
| 2,8–3,5s | Pílula de escassez | pulso sutil (chama atenção sem piscar) |
| 3,5s → loop | Setas do CTA | sobem em loop contínuo (a âncora visual do swipe) |

Som (opcional): batida curta/whoosh no momento da headline. A maioria assiste sem som — **a peça tem que funcionar 100% mudo**.

## 7. Variações de entrega (kit de story)

Recomendo produzir o lançamento como **sequência de 3 stories**, não 1 isolado:

1. **Story 1 — Tensão/curiosidade:** "Você anuncia e não vende? Tem motivo." (sem oferta ainda, gera abertura)
2. **Story 2 — A peça principal** (Variação A acima): oferta + escassez + CTA swipe.
3. **Story 3 — Prova social/urgência final:** print de resultado de aluno OU "restam [X] vagas" → CTA repetido.

Para o dia do fechamento: republicar o Story 2 com o badge trocado para **"ÚLTIMAS HORAS"** em vermelho.

---

## 8. Checklist antes de publicar

- [ ] Link de inscrição testado (abre? carrega no mobile? pixel disparando?).
- [ ] Nº de vagas e deadline são **reais** e batem com a landing page.
- [ ] Headline legível em 1 segundo, sem texto na zona morta.
- [ ] Sticker de link posicionado logo acima do CTA escrito.
- [ ] Peça funciona sem som e sem swipe (caso a conta não tenha link sticker → usar "link na bio" / "me chama no direct").
- [ ] UTM no link (`utm_source=instagram&utm_medium=story&utm_campaign=lancamento_mentoria`) para o tráfego rastrear a conversão.
- [ ] Versão "últimas horas" agendada para o último dia.
