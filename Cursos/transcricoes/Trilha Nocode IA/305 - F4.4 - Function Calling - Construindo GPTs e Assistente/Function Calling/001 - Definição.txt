Então vamos entender a definição e o que são Function Calling. Vamos lá para a gente entender sobre funções. Bom, os modelos de inteligência artificial, como por exemplo o Chapti e EPT, eles têm algumas limitações. Geralmente é um pouco mais difícil a gente conseguir dados atualizados, como por exemplo ter acesso à internet, conseguir algum dado atualizado que a gente precisa do dia, dificuldade em realizar ações específicas. Então toda vez que a gente faz uma pergunta, por exemplo, qual é o clima da minha cidade hoje? ele não consegue porque ele está atualizado até determinada data. Então essas ações, como por exemplo, qual é o clima hoje da minha cidade, qual o valor do dólar hoje, ou até fazer uma função personalizada, como por exemplo, mande um e-mail para mim, é um pouco mais difícil. Mas é para isso que a gente tem Function Calling para conseguir chamar funções específicas para conseguir essas informações. Então Function Calling na tradução literal é... chamar uma função, tá? E tem basicamente dois objetivos. Primeiro, a gente consegue chamar alguma função para ser executada via API e além disso, a gente consegue pegar essas respostas que a gente está organizando e converter em formato estruturado, que você já vai entender o que é isso. É importante deixar bem claro aqui que o chat GPT ou qualquer outro modelo de inteligência artificial, quando ele está chamando funções, ele não vai executar a função, tá? A gente não vai criar a função lá dentro. Aí a gente vai ter que ter uma API externa para executar essas funções. Então ele vai chamar essa função, mas a gente vai ter que conectar com uma outra API externa. Você já vai entender, bora lá. Então basicamente esse é o desenho resumido, né? A gente tem um prompt, que é uma linguagem natural, ou seja, é realmente um texto como a gente estivesse falando. Esse prompt vai para o chat GPT ou qualquer outro modelo de internet artificial. E aí é ativado uma função para chamar uma API, tá? E essa resposta, ela vai ser estruturada tanto quanto na entrada quanto na saída. Ou seja, a gente vai conseguir exatamente aqueles valores que a gente está querendo. Por exemplo, o usuário pergunta, qual foi o meu gasto em dezembro de 2023 na categoria lazer? Vamos supor que a gente tenha um banco de dados, lá de um app financeiro, e a gente consegue ter acesso aqui aos dados dos gastos. Então, isso daqui é um dado não estruturado, tá? Isso daqui é uma linguagem natural, ó. É uma forma como a gente fala, por isso que é natural. E o que as Function Calling vão fazer? Ela vai identificar a estrutura necessária e vai pegar, por exemplo, o mês dezembro de 2003. Vai pegar exatamente o mês e categoria lazer. E daí a gente vai conseguir esse dado estruturado para a gente chamar API. Basicamente, ele vai transformar a linguagem natural em uma linguagem estruturada para a gente conseguir fazer uma chamada API. Se a API também... der uma resposta em linguagem natural, um texto, a gente também consegue converter depois em dados estruturados. Então pode parecer até que não é grande coisa, né? A gente pegar esse texto e converter nisso daqui, ó. Basicamente ele vai entender quais são os parâmetros que ele quer e vai converter isso daqui, mas vai ser muito poderoso pra gente conseguir ativar essas funções APIs. Então pra gente entender quais são os benefícios disso, qual que é o poder de usar funções dentro aí das nossas ferramentas de IA. Primeiro, a gente consegue criar um chatbot que ele ativa qualquer tipo de função. Então ele consegue pegar dados atuais, ele consegue também ir atrás de banco de dados. Ele consegue acessar qualquer tipo de banco de dados da sua empresa para fazer uma pergunta em relação àquilo. Então a gente consegue ir lá no banco de dados pegar esses dados específicos para usar dentro do nosso chat ou de qualquer outro tipo de inteligência. Além disso, a gente consegue converter perguntas no formato estruturado. Então a gente tem linguagem natural, a gente converte naquele formato estruturado, né? Um mês e... o gasto exato, né? Isso tem o formato estruturado que a gente precisa pra fazer, por exemplo, chamadas API. Também a gente consegue converter respostas aí da nossa API no formato estruturado pra gente jogar de volta no nosso app, tá? Então, basicamente é isso. Em resumo, o function calling vai ser conseguir identificar que precisa de uma função e transformar um dado não estruturado em um dado estruturado, tá? Uma linguagem natural em um dado estruturado. E pra você entender... A gente tem alguns modelos, né, que a gente consegue fazer isso. A maioria dos modelos, ele já tem o tipo de chamar funções, tá? O que a gente vai usar mais aqui é o da OpenAI, por estar tudo mais estruturado, mais organizado, mas também você conseguiria utilizar a Function Calling tanto no Gmini, tanto no Cloud, tanto também no Lama da Meta, tá? Que é a Open Source. Então, já tem essas funcionalidades, a maioria dos modelos estão trazendo e vai seguir sempre o mesmo padrão. Então, se você aprender aqui, toda estrutura, você vai conseguir replicar para qualquer outro modelo.
