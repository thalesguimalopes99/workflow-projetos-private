Bora lá então, pessoal, começar a criar a nossa primeira automação, nossos cenários aqui, gatilhos, e depois conectar os aplicativos, esses gatilhos. O que a gente vai estar aprendendo inicialmente, falando um pouquinho de fundamentações para nossas criações de automações? Aqui nessas nossas próximas aulas, a gente vai entender os principais conceitos que tem, que a gente vai utilizar basicamente em todas as nossas automações, é basicamente 80 a 20 de qualquer automação que a gente vai criar. Primeiro, a gente vai configurar o nosso gatilho, entender como criar um gatilho, configurar quais são os gatilhos possíveis, entender um pouquinho. essa estrutura de gatilhos. Nenhum grande segredo aí. Depois a gente vai aprender a integrar esse nosso gatilho com novos aplicativos que a gente vai estar conectando, né? E aí configurar esse aplicativo, entender um pouquinho como é que funciona a questão de autentificação disso. E aí depois também entender como é que a gente faz a configuração para de fato receber os dados que a gente quer ali dentro. Beleza? Posteriormente a gente vai entender um pouquinho mais como colocar dentro desses nossos aplicativos dados dinâmicos, né? Então... Eu posso tanto colocar dados escritos manualmente, quanto pegar dados dinâmicos, tanto de módulos anteriores a essa nossa automação, quanto dados que vêm já sistemáticos. A gente pode tratar esses dados, fazer algumas informações com eles. Ainda nessa parte de colocar dados dinâmicos e tratar dados, a gente vai aprender a fazer uma coisa que é extremamente importante, que é a parte de manipulação de dados. e a gente também aprendeu um pouquinho sobre fazer um parse de dados, DataParse, basicamente. Aqui vive grande parte do que a gente vai fazer nas automações, integrar aplicativos, fazer a configuração dessas integrações e manipular dados entre um aplicativo e outro para que o dado que chegou em um lugar vá para outro lugar da forma como essas duas aplicações estão esperando. Então, essa é a grande parte do nosso trabalho, quando a gente está criando uma automação. A gente vai falar um pouquinho de filtros, também porque envolve... como que esse nosso dado vai fluir na nossa automação, se ela vai fluir para um lado, se ela vai fluir para outro, se ela vai fluir para todos os lados, enfim. Então, a gente vai configurando o dado para onde ele flui, como ele flui, manipula esse dado e faz com que cada lugar receba o dado da forma como ele quer. Então, a gente vai comentar um pouquinho sobre isso. E aí, por fim, a gente vai comentar sobre os dois grandes nódulos que a gente vai estar utilizando também massivamente nas nossas aplicações, que são fazer chamadas de APIs personalizadas. Então, a gente vai aprender um pouquinho sobre isso. e também como utilizar o Webhooks dentro das nossas automações para a gente integrar com qualquer aplicação que a gente precisar também. Então aqui, basicamente, está um 80-20 das nossas automações, dos nossos cenários. De fato, é o que a gente mais vai estar fazendo. Então a ideia é a gente fazer um entendimento desses fundamentos. Isso aqui vai se aplicar para qualquer automação que você for criar, qualquer ferramenta de automação que você for utilizar. Esses são os conceitos principais. Então a gente fazer, estruturar o B1 gatilho, estruturar as integrações, fazer uma... estrutura de fato como essas integrações vão acontecer, manipular esses dados, então manipulação de dados acontece o tempo inteiro, o dado chegar de um jeito e mudar para outro, fazer filtros dessas integrações e utilizar chamadas de API Webhooks para fazer de fato a conexão com o aplicativo que a gente quiser. Beleza? Na próxima aula a gente vai agora sim de fato começar a colocar a mão na massa, criar nossa primeira automação, tendo em vista tudo isso que a gente comentou. Beleza? Vejo vocês na próxima aula.
