Aqui, eu estou no nosso módulo anterior, que a gente havia criado, utilizando esse módulo aqui de assistants do próprio mic, de mensagem de assistants. Então, esse processo aqui está todo como eu comentei. acontecendo por debaixo dos panos quando a gente utiliza esse módulo. Aqui então a gente já fez uma verificação, se o usuário existe, ou seja, a thread existe. Aqui eu criei a thread, a gente criou a thread, criou a mensagem, enviou a mensagem, adicionou essa thread aqui no Google e aqui embaixo a gente, agora já com a thread existente, a gente veio para o caminho de baixo. Então, a gente antes lá tinha só enviado a mensagem para esse módulo aqui de Messaging Assistant. Ele já fazia um monte de coisa. Agora, não. A gente vai fazer isso manualmente. A gente vai criar a thread. A gente vai fazer uma chamada para criar a thread. A gente vai adicionar a nossa mensagem que a gente recebeu aqui no Webhook nessa nossa thread. Adicionamos a mensagem no threads. A gente agora... roda a nossa run, e aqui para rodar a run, a gente basicamente pega o nosso assistente, que é o assistente que a gente criou lá, o id dele, a gente pega o id da nossa thread, e a gente unifica esses dois aqui nessa nossa run aqui, e roda essa run. Rodamos a run, aqui nesse processo a gente adiciona a mesma coisa que a gente fez no nosso outro módulo aqui, que a gente criou a thread aqui, a gente cria todo o nosso usuário com o WhatsApp e a thread aqui. Então a gente faz esse processo aqui também. Então rodamos a run, adicionamos as informações na nossa Google Sheets. Aqui a gente faz um processo de esperar, aguardar algumas informações, porque aqui a gente vai verificar o status dessa run. Se o status da run foi completo, está completo, a gente pode seguir para o nosso fluxo aqui de status completo e agora verificar a última mensagem da nossa thread, pegar essa última mensagem e responder para o nosso WhatsApp. Ou seja, a última mensagem é a mensagem criada. pelo assistente, que a nossa run teve status completo. Caso ela não tenha status completo, a gente tem que aguardar que esse status esteja completo para a gente seguir para cá. E aí, como a gente viu, se a gente tem uma necessidade de função, uma chamada de uma função, a gente tem que vir para o required action. Então, nesse processo aqui, deu o required action, a gente vem para cá, para esse caminho agora. Agora, no required action, a gente vai fazer a nossa chamada de API aqui. Então, aqui eu tenho uma chamada de API que eu estou fazendo para a nossa função. Se a nossa função é executada, ela retorna aqui uma resposta para essa função. Eu preciso responder a função lá na nossa run, na nossa thread, respondo essa função e agora, novamente, a gente fica verificando o status da nossa run até ela ter que ser completa. Essa run sendo completa, a gente agora sim vai responder o usuário com a última mensagem.
