Pessoal, nas próximas aulas, nosso objetivo vai ser criar um assistente com Function Calling. A gente conseguir chamar uma chamada de API no qual a gente vai utilizar ela para fazer uma conversação com uma base de dados que vai estar lá no nosso Google Sheets nesse momento. Porém, para a gente fazer isso, a gente precisa ter a possibilidade de fazer essa Function Calling. E aí, uma limitação que a gente tem hoje ainda nesse módulo aqui que a gente utilizou nas últimas aulas de enviar uma mensagem para os assistentes que a gente tem pronto aqui dentro do Make, ele tem a limitação de a gente não conseguir fazer chamadas de funções ainda fazendo uso desse módulo aqui. Ele é um módulo que nos ajuda demais, de novo a gente já viu o quão simplificado ele deixa aqui a nossa mensagem, a gente consegue estar conversando com PDFs aqui, a gente consegue fazer todo o prompt do nosso assistente, tem toda uma facilidade aqui de gerenciar as threads também, então ele faz tudo isso aqui para a gente de uma forma bem facilitada, porém ainda eles não conseguem fazer as chamadas de API. É algo que... lá na requisições de melhorias do Make, eu já também enviei lá a mensagem para o Make, e eles já estão como planejado a melhoria nesse módulo aqui de adicionar a possibilidade de fazer function calling, mas ainda não é possível. E aí por conta disso, nas próximas aulas a gente vai aprender a fundo sobre como que funcionam os assistentes, porque por debaixo dos panos desse módulozinho aqui, parece que não tem, mas tem muita coisa envolvida. E aí só para vocês terem uma ideia, é que... Esse é o desenho que a gente vai precisar construir nas próximas aulas para executar a nossa conversação com esse assistente e a chamada de uma função. E para vocês terem ideia, se eu deletasse esse pontinho aqui, essa basezinha aqui, essa basezinha e essa basezinha que são informações iguais, o restante que sobra, todo o restante que sobra, é exatamente a mesma coisa do que isso que a gente acabou de criar. Então, a função é só esse bracinho aqui que a gente vai estar criando. O resto, a gente precisou fazer tudo isso para replicar isso daqui, porque a gente tem diversas chamadas que acontecem nesse moduzinho aqui que o Make está escondendo para a gente. Como, por exemplo, a gente tem que criar uma thread, a gente tem que adicionar uma mensagem na thread, a gente tem que rodar uma run, que é a forma como o assistente funciona, a gente tem que ver o status dessa run, e aí, por aí vai, coisas que a gente tem que validar e verificar. para que o nosso assistente aconteça. Tem várias coisinhas em volta dele. Então o Make acaba facilitando com aquele módulo, porém, ainda no momento, por ter essa limitação de Function Call, a gente não consegue utilizar ele com esse objetivo. Então nas próximas aulas a gente vai aprofundar aqui na arquitetura desses assistentes mesmo, o que é necessário para a gente fazer a construção desses assistentes do zero. Isso vai dar um conhecimento base fundamental para a gente, para a gente basicamente fazer as chamadas desses assistentes em qualquer ferramenta que a gente quiser. seja via N8N, seja via diretamente no Flutter Flow, no Bubble, enfim, qualquer outra ferramenta que a gente queira fazer o uso, a gente vai estar utilizando desse conhecimento e novamente aqui possibilitando fazer as chamadas de funções. Então, vejo vocês nas próximas aulas para a gente iniciar essa jornada de criação desse nosso assistente.
