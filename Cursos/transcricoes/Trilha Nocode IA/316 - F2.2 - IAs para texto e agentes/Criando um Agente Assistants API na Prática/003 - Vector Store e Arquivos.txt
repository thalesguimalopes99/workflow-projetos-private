Fala, pessoal! Gravando essa aula aqui rapidinho, porque as coisas estão evoluindo sempre a uma velocidade muito rápida. E a gente agora tem, dentro aqui dos nossos assistentes, a função de VectorStores, que são as nossas bases de dados vetoriais separadas. Então, o que muda nisso é que quando a gente vai adicionar um arquivo dentro do nosso assistente, agora a gente também cria uma VectorStore. Então, as VectorStores podem ser compartilhadas entre assistentes. Então, assistentes podem ter VectorStores. E a gente pode ter VectorStores para cada thread, que na verdade é cada conversação que a gente tem com esse nosso assistente. Então se eu tenho uma conversação, outra pessoa pode ter outra conversação e cada uma dessas conversações pode ter uma VectorStore individual para essa thread, que é chamada essa conversação. Então a gente tem VectorStores agora para os assistentes e também VectorStores para as nossas threads. Então sempre que a gente vai adicionar um arquivo... Se adicionar aqui o arquivo lá da Plano Financeiro da Rose, por exemplo, quando a gente vai adicionar, ele já vai criar uma Vector Store para a gente. Então, eu posso até selecionar alguma Vector Store se eu quiser utilizar para algum nosso assistente. O assistente pode ter uma Vector Store e a Thread hoje pode ter uma Vector Store nesse momento. Essa é a atualização que a gente teve nesse mês de agosto na OpenAI. Então, até agora a gente vê aqui que a gente em Storage, quando a gente vem para cá, a gente tem todos os arquivos que a gente adicionou. E a gente também tem aqui as nossas Vector Stores, os detalhamentos sobre elas. Então só uma linha para deixar isso claro, as coisas estão evoluindo muito rápido. E para vocês não ficarem perdidos com relação a isso, é uma funcionalidade que dá muita flexibilidade para a gente gerenciar esses nossos arquivos dentro dos nossos assistentes. Então aqui no nosso assistente amigo financeiro que a gente construiu, eu tinha adicionado aquele arquivo do plano financeiro da Rose. E aqui agora, para adicionar ele, a gente criaria... Da mesma forma, adicionando aqui, clicando adicionar arquivo, seleciona o arquivo, adiciona lá, ele já vai ser adicionado por debaixo dos panos. A OpenAI está criando uma VectorStore para esse nosso assistente. Beleza? Uma aulinha aí só para complementar um pouquinho o que a gente passou na aula passada. Um abraço.
