Beleza, pessoal? Com isso a gente chega ao fim desse nosso segundo módulo aqui, nesse nosso curso, onde a gente focou em estruturar o nosso banco de dados no Zeno, olhando especificamente para o Zeno, e deixar ele preparado para que a gente consiga integrar com qual front-end a gente precisar. Então, o que a gente aprendeu aqui nesse nosso segundo curso? A gente basicamente fez um breve planejamento do projeto, onde a gente entendeu quais eram... o banco de dados que a gente precisava, então quais eram as tabelas que a gente precisava e seus campos. Claro que a gente já tinha um entendimento aqui do que a gente ia precisar fazer lá nos nossos front-ends no futuro, então a gente trouxe um planejamento bem mais simplificado aqui, foi basicamente a modelagem de dados que a gente precisar. Posteriormente, a gente pegou essa modelagem e a gente passou, de fato, para o Xenon. Então, a gente implementou essa modelagem. Colocou todas as tabelas, os campos, fez as configurações nos campos necessários. E, por fim, a gente foi criar os nossos API Endpoints. Então, criamos os API Endpoints que a gente ia precisar no futuro, quando a gente fosse integrar com os frontchains. Primeiramente, a gente criou os API Endpoints de autentificação. Depois, a gente criou os API Endpoints de CRUD da nossa tabela de filmes, para que a gente consiga fazer... Primeiro, o login e cadastro do nosso usuário e nos API Endpoints de CRUD para a gente fazer, tanto criar um novo filme, editar o filme, deletar o filme, pegar todos os filmes, pegar um filme específico. Perfeito. E como a gente vai precisar fazer o upload de algumas imagens, para a gente ter imagens de capa e as imagens de miniatura na nossa aplicação, a gente também aprendeu a como estruturar os nossos API Endpoints e o nosso banco de dados para que ele consiga receber as informações de imagens e que, de fato, as imagens sejam armazenadas no storage do Zen da forma como... a gente quer. Então a gente também aprendeu a fazer essas manipulações de dados no Xenon para a gente fazer o upload de imagens. Beleza, pessoal? Espero que tenham curtido aqui essa nossa primeira introdução, esse nosso primeiro curso aqui estruturando o nosso banco de dados. Vejo vocês aí nos nossos próximos cursos, onde a gente vai estar integrando com os front-ends, seja ele Bubble, Web ou o Flutter Flow.
