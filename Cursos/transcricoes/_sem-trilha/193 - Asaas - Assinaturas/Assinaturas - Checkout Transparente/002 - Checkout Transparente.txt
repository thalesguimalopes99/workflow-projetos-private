Agora que vocês já entenderam tudo sobre as assinaturas, o que elas são, qual é a diferença entre uma cobrança parcelada e uma assinatura, eu vou mostrar para vocês o nosso novo checkout, que é o checkout transparente. Antes, lembra que quando a pessoa iria fazer o checkout, ela abria uma nova página, dentro dessa nova página ela colocava os dados do cartão, e aí a partir do momento que ele colocava os dados do cartão, voltava depois para a página do nosso aplicativo, e isso causava um pouquinho de insegurança, as pessoas ficavam... meio inseguras em colocar os dados do cartão em uma outra página, com o checkout transparente ele não é assim, tá bom? O checkout transparente, a loja, ela tem uma comunicação com a API, essa API responde enviando os dados diretamente para o front-end, para o nosso aplicativo, para a nossa loja. E essa resposta, como está falando aqui no nosso exemplo, ela é visualizada em um front-end próprio, sem que o usuário saia da página. E quais são as vantagens disso, galera? Primeira coisa, a coleta de dados é toda feita dentro do aplicativo e isso é muito seguro, as informações ficam seguras lá dentro. A experiência do usuário, que é a User Experience, que é a UX, ela acaba melhorando muito. O usuário se sente mais seguro e é um processo que acaba sendo mais simples. Eu não preciso ir para uma página, depois eu colocar os dados, volta. Não precisa disso, vai ser feito tudo lá dentro da nossa página do próprio aplicativo, do próprio Flutter Flow. É claro que tem um pequeno contra, que é a parte de complexidade. A gente vai ter que tomar muito mais cuidado com todas as informações passadas para a API. E também a gente vai ter que adicionar muitos campos ali dentro da API. Só que eu tenho certeza que vai valer a pena e vocês vão gostar bastante, tá bom? Então, agora que vocês já entenderam como funciona o checkout transparente, vamos entender o que nós vamos fazer aqui dentro do nosso módulo de assinatura do ASUS. A primeira coisa é nós vamos configurar a página de pagamentos do Flutter Flow para criar o nosso checkout transparente, que nem eu expliquei para vocês. Depois nós vamos criar a nossa chamada API com todos os campos que foram criados já na página do checkout transparente, como por exemplo, o nome, documento, o número do cartão, a data de validade do cartão, o CVV. E para finalizar, nós vamos fazer a verificação daquela assinatura, se a assinatura está paga, se o valor foi feito com sucesso, se está tudo bem, e verificar se aquela assinatura foi feita, o pagamento dela naquele mês, utilizando uma automação, utilizando os webhooks que o Matheus Castelo já apresentou para vocês lá na nossa introdução. Mas caso não lembrem, eu vou dar uma leve refrescada para vocês antes de a gente começar a colocar a mão na massa. Mas agora que vocês entenderam o que nós vamos fazer, vamos agora entender e conhecer a nossa documentação da API do Stripe agora com as assinaturas. Vamos lá?
