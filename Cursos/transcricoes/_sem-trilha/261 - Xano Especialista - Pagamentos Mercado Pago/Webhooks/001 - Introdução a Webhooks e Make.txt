Bom pessoal, e agora que nós já conseguimos criar a nossa preferência de pagamento no mercado pago, já conseguimos fazer algumas validações tanto no nosso endpoint como na nossa base para evitar ali cadastros duplicados e até mesmo localizar cadastros que já existem, chegou a hora que a gente precisa... receber a informação se o pagamento foi realizado ou não pode se entender que diversas vezes a gente não vai ter certeza se após a gente mandar o comprador ali para a página do mercado pago se ele vai voltar ali para a nossa página ou não e caso ele não volte a nossa página precisamos deixar tudo configurado para que o mercado pago nos enviem as notificações quando os nossos compradores, nossos clientes efetuarem algum pagamento. E para isso a gente vai utilizar o Webhooks. Webhooks é um método de comunicação ali entre APIs através de HTTPost, onde vai ficar um serviço só escutando as notificações. Essas notificações, por exemplo, enviadas pelo mercado pago. E como que funciona? Webhook é uma função de comunicação entre aplicações. Então no nosso exemplo a gente vai precisar encaminhar o comprador para uma página do Mercado Pago e assim que o Mercado Pago receber esse pagamento ele automaticamente vai nos enviar uma mensagem para que possamos através do identificador que o Mercado Pago enviar localizar quem que é o cliente, qual que é o pedido. Então dessa forma a gente passa a identificar o nosso cliente na nossa base. Nós vamos passar ali pela configuração tanto do WebRogue como também na validação do endpoint. Então, dentro do Mercado Livre, vai ser possível que nós configuramos o nosso serviço, que é um link URL, para que toda vez que ele for notificar um evento, ele só mande uma mensagem para aquela URL. Os eventos que nós vamos ser notificados são pagamentos, planos de assinatura e também split de pagamento. No Zano, nós só podemos criar tasks de background se estivermos a partir do plano launch. E como podem ver, é um pouco salgado. E como estamos construindo esse app totalmente no plano Free, nós decidimos não fazer e não configurar os webhooks aqui dentro do Zano. Então, para trabalhar com isso, nós vamos utilizar uma ferramenta muito poderosa de automação chamada Make. Através do Make, nós podemos fazer facilmente integrações com diversos aplicativos já nativos dentro do próprio Make. Além disso, é possível fazer diversas automações no nosso fluxo de trabalho e o melhor, com todas as ferramentas no Code. É muito simples começar ali a trabalhar nos fluxos. O projeto que a gente vai desenvolver, o cenário que a gente vai desenvolver aqui também é muito simples de fazer para que a gente consiga concluir. Um outro ponto bastante importante é que os preços são totalmente acessíveis do Make. A planos a partir de 10 dólares e 50. E a gente vai conseguir criar módulos dentro do cenário para que nós possamos fazer chamadas APIs e também criar o nosso próprio Webhook dentro do Make. Vamos lá?
