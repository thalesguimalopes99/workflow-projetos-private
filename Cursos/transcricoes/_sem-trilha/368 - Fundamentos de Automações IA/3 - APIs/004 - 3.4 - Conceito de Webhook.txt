Antes de explorar a documentação de APIs na prática, a gente tem que passar um conceito muito importante, é o conceito de Webhook, tá? O que é Webhook? Bom, pra resumir, a API, como que ela vai funcionar, tá? O cliente vai fazer um pedido e o garçom, que é a API, né? Vai levar o pedido pra cozinha conseguir saber qual pedido que é. A cozinha vai preparar o pedido e vai voltar aqui, ó. O garçom API retorna com o prato. Então, é importante que você entenda que a API sempre vai e volta. A gente faz um pedido ativamente. Esse pedido vai até o nosso servidor e volta com essa resposta, tá? E o Webhook é um pouco diferente, ó. O Webhook seria como se a cozinha avisa automaticamente. A cozinha avisa automaticamente que o pedido está sendo preparado e já vem aqui para o cliente, tá? Então, para você entender um pouco melhor, aqui em API a gente pede um dado. E ele traz o dado. O Abhook não. Ele envia o dado automaticamente. E pra que que é útil? É útil, por exemplo, quando a gente quer ver se o cliente, ele já fez um pagamento de um boleto. Então, eu não vou ficar perguntando toda hora pra API de uma plataforma de pagamento. Ah, o cliente fez pagamento? Pergunta toda hora, sabe? Porque isso daí vai deixar muitas requisições do banco de dados e vai ser péssimo pro seu projeto de automação, seu projeto de aplicativo, tá? Então, o que que eu quero que faça? Eu quero avisar... falar lá para o meu gueto de pagamento que quando tiver um pagamento ele me avise automático então é basicamente isso para pagamento às vezes para recebimento de um e-mail ou para saber qualquer tipo de aviso a gente faz um webhook que basicamente ele vai ficar ouvindo esperando o pagamento enviar aqui um dado tá então para você entender um pouco melhor a gente tem aqui o nosso plataforma nosso software a gente tem o asas ou stripe que são gueto de pagamento depois a gente vai falar um pouco mais sobre isso Em APIs, eu teria que ficar perguntando, esse cliente pagou? Aí ele volta com a informação, não, não pagou. Dá para fazer também, mas a melhor forma é o Webhook. Os APIs aqui, eles já vão avisar automaticamente quando for feito o pagamento. Então, ele já avisa automaticamente. Ou, por exemplo, uma assinatura, se o cliente não paga a assinatura dele, a API vai avisar via Webhook que já foi pago automaticamente. Como a gente vai fazer isso para a automação? lá no Noitwin a gente vai colocar um webhook que ele vai ficar esperando ele só fica esperando e aí quando acontecer algo a outra plataforma já avisa e aí a gente consegue executar a nossa automação, tá? mesma coisa aqui pro WhatsApp, então no WhatsApp a gente vai precisar de alguma API, por exemplo, azAPI, mega API, Evolution API a gente precisa ter um webhook lá no Noitwin que ele vai ficar esperando receber alguma mensagem então quando a gente receber alguma mensagem no WhatsApp o nosso agente ele vai responder automaticamente E daí vai disparar o nosso N2N, o nosso Adify. E daí ele já dispara tudo, tá? Então, esse daqui é um outro exemplo. A gente vai usar o Abhook. Depois a gente vai usar na prática. E você vai entender um pouco melhor como que vai funcionar o Abhook. Então, bora pra próxima aula.
