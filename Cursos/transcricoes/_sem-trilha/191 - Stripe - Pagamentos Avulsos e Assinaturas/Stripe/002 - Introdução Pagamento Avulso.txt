Seja bem-vindo ao módulo do pagamento a vôs. onde eu vou estar explicando para vocês e ensinando o passo a passo de como você realiza esse pagamento de forma avulsa, de um valor único. Lembrando que a gente tem três formas e a forma que eu vou estar iniciando vai ser a primeira forma, que é a ação nativa. Lembrando que essa ação nativa é apenas para um pagamento mais simples e a verificação desse pagamento é feita na hora dentro do próprio Flutter Flow. O cronograma para esse pagamento nativo vai ser, primeiramente, entendendo o que é essa ação. como que você configura ela e depois fazer toda a parte de mão na massa. Então a gente vai conectar o Stripe com o Flutter Flow, a gente vai criar um produto dentro do nosso aplicativo conectado ao Firebase e depois a gente vai colocar ali a ação que é do Payment do Stripe dentro ali do nosso projeto e verificar se o status daquele pagamento foi feito mesmo ou não, tá bom? Então vamos lá, bora começar mão na massa. Todos prontos? Agora que você já fez toda a ação nativa do Flutter Flow para consumir uma verificação de um pagamento a bolso, eu vou estar introduzindo para vocês como fazer esse mesmo processo agora utilizando a API. A gente está falando aqui da segunda forma que eu expliquei para vocês, aonde eu vou estar realizando cobranças e também verificando se o status daquela cobrança está paga ou não agora com a API. O cronograma do pagamento a bolso via API vai ser muito simples. A gente tem primeiro como que funciona essa integração para a gente poder conectar ali as informações. Depois a gente vai conhecer a documentação. Eu vou ler junto com vocês todas as informações ali que são muito importantes dentro da documentação do Stripe. E para finalizar a gente vai colocar a mão na massa adicionando um produto dentro do Stripe via uma API. Depois a gente vai criar uma seção de checkout e para finalizar nós vamos verificar o status desse checkout. E bom, como nós vamos fazer isso? A gente vai estar utilizando, primeiro, a API de post, ou seja, a gente vai publicar um produto. Então, aí a gente tem como criar um produto com o nome, o preço, a imagem e o ID desse produto, tá bom? Que é muito importante. Eu tenho que saber qual produto que o meu cliente está comprando. Então, eu preciso de um ID dele. E é o que nós chamamos ele de price, tá bom? Não é o preço, tá? Quando a gente está falando de price, é o ID do produto, tá bom? Segundo... Eu vou fazer uma outra chamada API de post, agora de uma checkout session, tá bom? Então eu vou estar criando aí uma sessão de checkout. E aí, esse checkout session, ele tem algumas informações, como qual que é o produto que eu estou criando uma sessão de checkout, né? Para qual produto que o usuário vai estar pagando, qual que é o preço daquele produto, qual que é o cliente e qual que é o status, tá bom? Então isso aí são as informações que são muito importantes aí nesse segundo passo. E o terceiro passo, aí a gente vai estar usando um GET, ou seja, eu vou estar buscando alguma informação. Agora eu vou estar buscando do Checkout Session, porque eu estou verificando se aquele Checkout Session foi paga ou não. E também eu tenho outras informações que são importantes ali dentro, mas a mais importante é se o pagamento foi feito com sucesso ou não. Então, esse vai ser o nosso parâmetro para verificar e aí a gente consegue alterar também o nosso banco de dados lá dentro do Flutter Flow. Então, vamos lá agora, agora que você já entendeu tudo isso, vamos então entender a documentação do Stripe, vamos conhecer lá por dentro e vou estar explicando para vocês aí como vocês vão evoluir e vão aprender como utilizar a documentação do Stripe. Vamos lá?
