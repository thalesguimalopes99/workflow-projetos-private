E como que vai funcionar essa verificação dentro do Flutter Flow? Existem várias maneiras de você fazer essa verificação da assinatura e eu estarei ensinando um jeito de você fazer isso, mas você pode olhar, lendo a documentação do Stripe, qual que é o melhor jeito que vai se adequar ao seu projeto para você fazer as verificações das assinaturas. Mas vamos primeiro lembrar qual que é o passo a passo aqui de como que funciona o nosso projeto. Aqui eu tenho uma página da lista de produtos. aonde quando eu clico naquele produto, eu navego para a página do produto, depois, aqui dentro, eu tenho várias informações que estão salvas no meu banco de dados, como nome, imagem, preço, mas o mais importante que eu preciso que vocês lembrem é sobre a API Price, que é uma informação, um ID do nosso produto que está sendo salvo e também compartilhado entre o nosso banco de dados e o Stripe, tá bom? Outra coisa, depois que a gente vai... e passa dessa página para a próxima página de pagamento, a gente clica aqui nesse botãozinho de realizar o pagamento. E é muito importante saber que quando a gente faz o checkout, que a gente cria essa ação aqui de criar a sessão de checkout, eu também vou estar criando um documento na coleção assinaturas. E esse documento aqui, ele possui o ID daquele checkout da assinatura. Ele tem salvo já no nosso banco de dados, então, o ID daquela assinatura. Por que é importante você saber disso? Nós vamos estar utilizando o nosso primeiro chamado API, vai ser um GET de Checkout Session. Eu vou estar buscando uma informação de uma seção de Checkout, aonde eu quero saber muitas informações que quando eu crio, nesse momento aqui, eu não tenho. Quais informações são essas? Se eu adicionar aqui, vocês vão ver. Primeiro. O status do pagamento. Outra, qual que é? O status da assinatura. Qual que é o customer? Qual que é a sub? Qual que é a assinatura em específico? O ID da assinatura. Então, essas informações aqui, quando eu crio a minha sessão de checkout, eu não tenho elas. Então, nesse caso, a gente vai ter como salvar essas informações, atualizar elas no banco de dados, na verdade, quando eu usar essa chamada de GET. Vamos olhar lá na documentação qual chamada que é. Então aqui eu vou entrar na minha documentação do Stripe. Vou procurar aqui qual que é a Checkout Session. E vou procurar a Retrieve, que é para receber de volta uma sessão de Checkout. Aqui dentro então a gente tem a nossa chamada de Get. Da sessão de Checkout, barra Sessions, barra... Aí vem o nosso ID variável. E aí galera, olha o tanto de informação importante que a gente tem aqui na nossa resposta, né? Eu tenho o meu Customer, eu tenho qual que é o modo, aqui nesse caso é um pagamento único, né? O status do pagamento que a gente vai salvar no nosso banco de dados e também qual que é a assinatura, no caso se for uma assinatura, né? Então essas informações, quando a gente der um GET, eu vou estar salvando também no banco de dados, tá bom?
