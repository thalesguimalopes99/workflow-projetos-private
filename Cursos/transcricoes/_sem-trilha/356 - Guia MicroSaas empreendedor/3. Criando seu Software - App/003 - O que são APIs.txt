Então agora vamos falar sobre APIs. E APIs nada mais é que a forma que os sistemas vão se comunicar entre si. Então a sigla API significa Application Programming Interface, tá? Que é uma interface para a gente conseguir ter essa comunicação. E basicamente uma interface para comunicação entre diferentes sistemas. Então se eu tenho meu software e eu quero que, por exemplo, ele tenha... Uma tecnologia da OpenAI de chat EPT. Eu consigo fazer isso de uma forma de API. Eu vou me comunicar com a OpenAI via API. Se eu quero colocar pagamentos. Eu vou me comunicar via API. Como por exemplo Stripe. Ou Mercado Pago. Qualquer outra função de pagamentos. Daqui é uma forma que a gente tem de API. E para explicar API. É bem interessante de usar o exemplo aqui do garçom. Então se eu tenho aqui meu cliente. E ele faz um pedido no restaurante. O garçom vai pegar o pedido desse cliente. Vai levar para a cozinha. A cozinha vai cozinhar esse pedido. E o garçom vai trazer de volta. O API nada mais é que faz parte aqui do garçom. Ele faz o papel do garçom. Ou seja, ele pega o que o cliente está querendo. Leva lá para o nosso banco de dados. Para o nosso paciente. E traz de volta aqui para o nosso front-end. Então o API sempre vai fazer essa comunicação. Se por exemplo eu quero um dado. Eu vou pedir aqui para o API. Ele vai até o nosso banco de dados. E volta aqui. com esse dado que eu pedi. Então a gente sempre vai ter o front-end aqui interagindo com o nosso back-end. E o nosso back-end pode ser tanto o nosso banco de dados como ser também outro sistema. Aqui dentro da formação a gente vai falar bastante, por exemplo, do Flutter Flow que é uma ferramenta de front-end. Então a gente vai criar nosso aplicativo, nossa interface no Flutter Flow e vai estar conectado lá com os serviços de back-end, de banco de dados como por exemplo o Supabase ou o Xeno. E o API ele vai fazer essa integração aqui. essa comunicação. No caso, o Flutter Flow tem uma integração nativa, o que funciona bem mais rápido. Mas a gente pode também fazer conexão de API aqui com os outros serviços, como eu falei. Então, se a gente quiser algum serviço da OpenAI ou do Stripe, a gente vai fazer toda essa comunicação via API, tá? Então... É nada mais isso que você tem que entender que a API vai fazer a comunicação entre sistemas. Vamos ver um exemplo de uma arquitetura de um SaaS para você entender onde que a gente tem ferramentas de front-end, de back-end e também ferramentas para a gente utilizar via API. Então aqui nesse desenho, depois a gente vai comentar mais sobre esse desenho lá na parte de aulas de no-code. Mas a gente tem aqui o Flutter Flow, mas aqui no desenho a gente tem o front-end, que é a interface, temos o banco de dados, o back-end e ferramenta de API. Front-end a gente pode construir com diversas ferramentas, tá? Por exemplo, a gente tem o Flutter Flow, a gente tem o Software, a gente tem o Bubble, o WhatsApp também, a própria interface, tá? Já que a gente tá conectando só a interface, a gente pode usar até o próprio WhatsApp pra fazer um bot. Em banco de dados, a gente tem principalmente o Supabase, que é um backend mais técnico, o Zeno, mas a gente também pode fazer automações aqui, integrações com o Make ou o N8N, tá bom? Essa daqui é uma forma da gente fazer essas integrações. E daí a gente consegue integrar com outras tecnologias, como eu falei, a OpenAI, o Gemini, o Stripe, ou o Google Maps, o Google Translator, qualquer outra tecnologia a gente vai fazer por meio de API, tá? Então, API é bem importante você entender que vai fazer toda essa conexão com o nosso sistema. E por que é tão importante aprender sobre API? Porque a gente vai conseguir integrar o nosso sistema com qualquer outra tecnologia, tá? Então, se a gente quer criar um SaaS com IA, a gente tem que saber API, porque toda essa conexão vai ser feita aí por meio de API. Por isso que é tão importante você aprender. E dentro do API, a gente tem os principais métodos. A gente tem o método post, o get, o put e o delete, tá? O post vai ser para criar novos dados lá no nosso back-end. O get vai ser só para puxar dados. O put para fazer atualizações de dados. E o delete para deletar dados. Então é importante você entender isso. Porque nas chamadas de API a gente vai fazer esses tipos de métodos aqui, tá bom? E agora a pouco a gente vai ver na prática. Então para ficar claro um resumo sobre APIs. Vamos por aqui no melzinho aqui das abelhas. A gente tem aqui o cliente, né? E a abelha vai pedir, precisamos de mais Nectar. Que é dados para o nosso app. A gente vai fazer uma chamada API que vai ser do tipo HTTP request, tá? É uma chamada via browser. E a gente consegue fazer o GET aqui para ir até o servidor, pegar os dados e voltar aqui com os dados. Então, primeiro faz a chamada. Depois que faz a chamada, recebe os dados que a gente quer. E aí, traz de volta como resposta, tá? A gente vai trazer a resposta aqui de volta. Então, mesma coisa aqui no nosso garçom. Ele vai e volta com a requisição e volta com a resposta, tá? sem muito segredo e a linguagem oficial aqui das APIs vai ser o Jason tá então a gente vai ver aqui um formato que ele é bem leve é uma leitura simplificada tanto para humanos quanto para máquinas e é possível criar relações complexas então no Jason a gente por exemplo aqui ó tem aqui os empregados e aqui vai ser um colchete que vai ser uma lista, tá? A gente vai ter, por exemplo, nome do empregado, idade, nome do outro empregado, idade. Então, a gente vai ter arquivos JSON. A gente vai usar na prática, é importante que você fique aí bem familiarizado, que a gente vai acabar usando muito JSON. Espero que você tenha entendido aí o resumo geral sobre APIs e agora nas próximas aulas vamos fazer alguns exemplos práticos. Então, bora comigo!
