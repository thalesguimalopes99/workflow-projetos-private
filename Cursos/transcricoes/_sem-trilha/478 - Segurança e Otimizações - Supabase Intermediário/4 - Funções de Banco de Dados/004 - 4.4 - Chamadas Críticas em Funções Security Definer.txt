Olá, nessa aula nós vamos aplicar uma chamada de função definida com o nível de segurança Security Definer. O que é Security Definer? É aquela função que tem o privilégio do administrador, do Supabase Admin. Porém, essa função será uma chamada crítica. O que é uma chamada crítica? Guarde bem esse termo. Chamada de update, chamada de delete, de insert são chamadas críticas, porque elas alteram o registro. Uma chamada de select, por exemplo, ela não é uma chamada crítica, mas uma chamada insert, update, delete, ela é uma chamada crítica. Por que eu estou fazendo questão de trazer essa diferença aqui? Porque na aula passada nós criamos uma chamada, criamos uma função que faz a leitura, E nós entendemos ali o Security Definer e também entendemos o Security Invoker, que é quem está invocando a segurança aplicada ao invocador e a segurança Definer, que é do Admin, que ele tem autorização para fazer qualquer coisa. Porém, quando se trata de uma operação crítica, que é Update, Delete e Insert, Se você utilizar a chave AnonKey em uma Security Definer, você vai ter problemas e não vai conseguir executar aquela chamada. E aí, qual é a obrigatoriedade? Colocar a Service Rule. Mas não recomendo você utilizar a Service Rule para qualquer caso, estritamente para caso necessário.
