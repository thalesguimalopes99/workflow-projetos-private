Tem o access token. Você se recorda ali da aula onde eu explico sobre o token da criação? Ele criou o usuário, logou o usuário e já deu para aquele usuário lá uma credencial para ele acessar o sistema. Esse é o access token. Isso aqui é o tempo de expiração desse access token, que isso aqui está em segundos. Então isso aqui representa uma hora de expiração, de validade. Aqui é quando que vai expirar em formato timestamp. Aqui é o refresh token. Nós vamos usar isso aqui nas outras aulas. quando iremos precisar renovar o token. Então, para você renovar esse token aqui de cima, você precisa desse carinha aqui, o Refresh Token. Aqui são informações do usuário.
