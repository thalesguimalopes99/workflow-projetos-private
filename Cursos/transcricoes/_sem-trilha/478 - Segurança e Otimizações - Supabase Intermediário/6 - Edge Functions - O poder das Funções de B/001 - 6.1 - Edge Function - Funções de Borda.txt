Olá, agora você vai começar comigo aqui o módulo de Add Functions. Esse módulo aqui é essencial para você se tornar um profissional de verdade de back-end, para trazer maior robustez, maior escala e maior performance nos seus bancos de dados, nos seus back-ends. Agora que você já sabe o conceito de funções, de triggers, já sabe aplicar as funções, Este módulo de AdFunctions vai fechar com chave de ouro todo esse ecossistema de funções de back-end. E, como de costume, esta primeira aula é uma aula conceitual, a próxima também, porque é muito importante que você entenda o conceito para você obter sucesso quando você for aplicar as suas funções. Então, sem mais delongas, vamos aqui para o nosso conceito AdFunctions. O que são as add functions? Elas são funções de borda. Então o nome add functions significa funções de borda. Por que funções de borda? O que são add functions? As add functions são funções de borda. Então por que elas são funções de borda? Imagine quando você selecionou o seu back-end. Estado de São Paulo, a cidade de São Paulo. E os seus usuários, eles estão espalhados pelo mundo todo. Eu coloquei uma distância bem alta aqui, mas para elucidar bem. Mas imagina aqui que seus usuários estão espalhados pela América do Sul, América do Norte, África, Ásia, Oceania. E estes usuários, eles precisam acessar os seus dados que estão lá no seu... eles precisam acessar ali as tabelas, as views, o storage, as funções RPCs que nós aprendemos, os triggers, e todo esse acesso, toda essa movimentação de usuários fazendo solicitações ali para o back-end, ele gera um índice, ele é passivo de um efeito que a gente chama de latência. O que é a latência? A latência é o tempo entre o momento que o usuário fez uma solicitação até o momento que ele recebe a resposta. Perceba aqui que eu coloquei, olha, esse usuário que está bem longe aqui, ele tem uma alta latência. Então, quanto mais longe o nosso usuário está da nossa estrutura, então, quanto mais longe o nosso usuário está da nossa estrutura física de banco de dados, maior vai ser... Essa latência maior vai ser esse atraso. Então, voltando aqui para o nosso exemplo, esse usuário aqui está com uma alta latência. Então, devido a isso, o que foi aprimorando, foi desenvolvido? No mundo todo, existe um ecossistema de servidores espalhado pela rede internacional, que é a internet. E esses servidores estão próximos dos nossos usuários. Eu coloquei um exemplo aqui, vamos imaginar que eu tenho um servidor próximo desse usuário aqui, que está aqui na América do Norte, e o ideal para que este usuário acesse, faça manipulações aqui no nosso back-end, seja através de uma add functions. Por quê? Porque essa AdFunctions vai diminuir o quê? Vai diminuir a latência. Ela vai dar para esse usuário aqui uma baixa latência. Enquanto esse usuário aqui que está longe, ou até mesmo esse, se ele não usar o recurso de AdFunctions, ele vai ter uma auto-latência. Então é por isso que servem as AdFunctions. O que a AdFunction faz? Ela tem todo um mecanismo, para que seja possível trabalhar cabeçalhos, trabalhar informações, trabalhar o JW token, trabalhar cache, N ferramentas que a AdFundance pode utilizar. E ela vai processando tudo isso e paralelamente ela também vai trabalhando ali com o nosso back-end. E com isso ela consegue entregar ali uma latência. Bem baixa, bem menor. Obviamente que tudo isso são frações de segundo. Se a gente for medir aqui no clique entre uma e outra, tem uma diferença, mas são frações de segundo. Mas aí imagina isso numa situação de milhares de usuários, onde esses inputs, esses acessos têm que ocorrer em alta escala. Então é aí que mora o segredo. É aí que você precisa aprender. a aplicar as Edge Functions. Então, apenas para a gente fechar aqui o conceito, as Edge Functions são funções de borda, elas nos ajudam a baixar a latência e normalmente elas são utilizadas para serviços como Webhook, chamadas APIs, manipulação prévia de dados e... Por estarem aqui na borda da rede, por elas serem executadas dentro de um servidor próximo ao usuário, elas usam uma linguagem chamada TypeScript para Robustez e Dino, porque isso é uma funcionalidade que o próprio Supabase já disponibiliza para que estes servidores aqui que estão próximos ao usuário possam trabalhar. O conceito de addFunctions e a importância das addFunctions você já entendeu nessa aula. E na próxima aula nós vamos fazer um comparativo. Por quê? Você deve estar se perguntando, mas eu tenho minhas funções. Quando é melhor usar a função rpc, que praticamente é o mesmo resultado de uma função de borda, e quando eu devo usar uma função de borda? Espero que tenha ficado claro. Na próxima aula a gente vai ver a... comparação de quando usar add functions e quando usar funções RPC. Um abraço, até a próxima aula.
