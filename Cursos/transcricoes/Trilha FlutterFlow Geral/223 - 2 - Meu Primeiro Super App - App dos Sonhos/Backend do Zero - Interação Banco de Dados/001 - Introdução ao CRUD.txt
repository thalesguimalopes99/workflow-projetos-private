Agora que a gente tem nosso aplicativo pronto em relação à parte de design, a gente tem as telas principais, a gente já pode fazer a conexão com o banco de dados. Então a gente vai fazer o setup no Firebase, a integração do Flutter Flow com o Firebase e depois a gente vai fazer o CRUD, que é interagir com o banco de dados. Pode ficar tranquilo que eu já vou te explicar como é que vai funcionar. E para quem nunca ouviu falar, operações CRUD é quando a gente consegue fazer uma interação no banco de dados de create, read, update e delete, ou seja, a gente consegue criar novos dados, a gente consegue ler esses dados que a gente vai criar no nosso banco, vamos conseguir também atualizar se a gente precisar atualizar algum dado ou deletar o dado. Então esse é o básico que a gente precisa aprender toda vez que a gente está criando o aplicativo. Provavelmente todo projeto de software, de sistema ou um app vai precisar fazer o CRUD com banco de dados. E como eu falei, o Flutter Flow é apenas o front-end. A gente conecta com o Firebase, com o Supabase ou com outro banco de dados e aí sim a gente consegue fazer o CRUD. Bom, e lá no nosso app como é que ele está organizado? Qual tela vai fazer qual parte dessa interação? Vamos passar para cá. Primeiro, nós temos a nossa tela Home. Aqui, a gente só vai precisar visualizar os dados do banco. Então, lembra que eu coloquei a foto do Bobinho aqui, né? E aqui tem a foto de outros sonhos também. Mas isso vai mostrar só dos sonhos que estão lá no banco de dados. Então, depois eu vou ter que apagar todos os outros e conectar ao banco de dados. Vai ficar bem claro quando a gente for fazer, tá bom? Pra criar novos dados, a pessoa vai clicar aqui, né? No mais. E aí, vai abrir aquele pop-up também que a gente criou, né? Então esse pop-up vai ser responsável por criar novos dados do nosso banco. Então o create da parte do crude. Perfeito. E depois, quando a pessoa clicar aqui, aquele nosso pop-up já está fazendo duas funções. Quer dizer, três funções juntas, né? A gente consegue visualizar os detalhes daquele sonho. A gente também, se a gente clicar aqui, a gente vai conseguir editar os detalhes do sonho. Ou, clicando aqui, a gente vai conseguir deletar. o sonho. Então a partir aqui dessas três telas bem simples, bem interativas, a gente consegue fazer toda a parte do CRUD. Então olha que legal, fica bem fácil a gente entender como criar um app. Então agora que você já entendeu a parte teórica, vamos lá para o projeto que a gente vai fazer primeiro a integração do Firebase com o Flutter Flow e vamos começar o nosso CRUD. Faça essa parte com muita calma para não ter problema lá depois.
