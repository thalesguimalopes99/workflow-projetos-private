Agora vamos lá para o nosso primeiro módulo, onde nós vamos estar entendendo como foi o planejamento do aplicativo, que é o projeto que nós vamos construir juntos. A primeira coisa que nós fizemos foi utilizar a metodologia da NoCode Startup para, primeiro, entender um problema. O problema é que existe no mercado e com as pessoas que são envolvidas. Então, o problema de um chat é basicamente a comunicação. Eu preciso comunicar com as pessoas, no caso, no meu dia a dia. Depois, a solução. conceitualizar a tecnologia que irá solucionar o problema. Então, como eu falei lá no aplicativo da escola, uma tecnologia que vai solucionar o problema seria um aplicativo com o chat. Depois, a gente passou para a parte do design das telas, onde utilizamos o próprio Flutter Flow para ir construindo as telas e entender como que funcionaria o fluxo dos usuários. Para finalizar, a gente criou um banco de dados, eu modelei um banco de dados para conseguir e relacionar e enviar informações de um usuário para o outro, tá bom? Primeiro, é claro, você precisa criar esse usuário, mas eu vou estar explicando isso com mais detalhes logo mais, tá bom? E por último, vem o desenvolvimento, que é onde você vai construir esse aplicativo, juntando as telas que você fez com o seu banco de dados, lembrando de resolver o problema, tá bom? Daqueles usuários. E aí, a gente conectou o front-end, são as telas, com o back-end. fazendo assim as nossas ações funcionarem da melhor maneira possível. Beleza, Neto? Então, quais são as telas do nosso aplicativo? Nós temos apenas três telas, que são a primeira, a lista de conversas, que do lado vai estar aparecendo o chat, e na versão mobile, a gente vai estar escondendo essa lista de conversa para aparecer apenas o chat. E, quando eu saio do chat, eu volto para mostrar apenas essa lista, e eu escondo o chat. Então, é a mesma tela, a gente só vai estar trabalhando ali. com condições de visibilidade, tá bom? Beleza. A segunda tela é a edição daquele perfil. Eu preciso mudar as informações de nome, imagem, qual que é o telefone, e-mail e assim por diante. Então a gente vai ter essa tela aí para editar aquele perfil. E a terceira tela é uma tela de criação de um novo chat com um usuário. Se eu não tenho uma conversa, como por exemplo ali com algum dos usuários que eu quero, eu preciso clicar naquele botãozinho lá embaixo para criar uma nova conversa. E assim eu navego para essa página para criar um novo chat com o usuário. Então são essas as nossas três telas. É claro que se você quer construir um aplicativo que nem o do exemplo da escola, isso aqui vai ser só uma pequena parte do aplicativo. Todo o resto você precisa desenvolver e assim você pega todo o conhecimento que você adquiriu durante essa nossa nova trilha e aplica para criar o sistema de chat para o seu projeto. Espero que vocês tenham entendido. Vamos agora visualizar essas nossas telas. Como vocês podem ver, na esquerda eu tenho a opção de editar o meu perfil com o nome, imagem, qual que é o meu número. E aí eu consigo tanto salvar quanto também sair do aplicativo, onde eu vou fazer o logout. No meio eu tenho a tela de chat, onde eu consigo ter uma conversa, como por exemplo, com o médico Fernando. E aí eu consigo enviar as mensagens e também ver quando ele envia uma mensagem para mim. E por último, na direita, nós temos a nossa lista de conversas, aonde eu vou estar buscando. Então, ali a gente vai ter o sistema de busca para estar buscando por alguma conversa. E aí, eu tenho também algumas conversas que estão acontecendo ali no nosso dia a dia, tá bom? Então, assim a gente consegue ter essa lista para visualizar as minhas conversas. Esse é o design do nosso aplicativo. Espero que vocês tenham gostado.
