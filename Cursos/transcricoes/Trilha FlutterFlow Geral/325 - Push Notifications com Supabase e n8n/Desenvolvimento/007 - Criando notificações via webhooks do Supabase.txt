Pessoal, no nosso exemplo final, a gente vai entender como enviar uma notificação através de um webhook no Supabase. Para fazer isso, eu preciso usar esse trigger aqui, chamado webhook. Ele basicamente fornece um endpoint para que o Supabase acesse toda vez que houver uma alteração em uma tabela, no sentido de adicionar uma linha, excluir uma linha ou atualizar uma linha. Então aqui eu vou utilizar o método post e vou copiar essa URL. Na sequência, eu só anexei esse cara a um bloquinho de HTTP, beleza? Lá no Superbase, eu venho aqui em Database, depois Webhooks e criar Webhook. Eu vou chamar de Notification. Na tabela, vai ser a tabela public.users, que é a nossa tabela de usuários. E eu vou falar que o evento vai ser Update, ou seja, toda vez que alguém atualizar a minha tabela, Ele vai mandar uma solicitação lá para o N8N e o N8N vai mandar uma notificação com base nessas informações. Então aqui é HTTP Request, método POST e a URL é aquela que a gente acabou de copiar. Dão criar webhook e pronto. O webhook já está criado. Agora eu posso voltar aqui no N8N. Deixa eu atualizar alguma coisa na minha tabela. Eu tinha colocado alguns testes aqui, tudo mal escrito, vou deixar só gratuito. Já está habilitado. Agora eu vou testar. Test workflow. Ele está aguardando um evento de trigger. Ok? Então eu vou atualizar. Agora ao invés de gratuito, agora é um usuário pagante. Vou clicar aqui. Pagante. Pronto. Ele já recebeu o trigger. Já ativou esse outro bloquinho. E já trouxe a notificação aqui para a gente. Às 8h11. Aliás, 8h52. Ok? Pronto. A gente acabou de fazer um teste usando o Webhook. Só recapitulando. Aqui nesse cara, o único ponto de atenção é o seguinte. O JSON que a gente usa, deixa eu abrir ele aqui no detalhe, mudou o caminho. Por quê? Agora, como é um webhook, ele vai trazer tanto o registro antigo lá do Superbase, quanto o registro novo. Você pode ver aqui através dessas informações. Record e Old Record. Old Record é a informação inicial. Lembra que estava gratuito? Ele trouxe aqui para a gente. Só que a informação atualizada está dentro de record, que agora está como pagante, beleza? É que a informação que a gente usou foi só o token. Então o token se manteve o mesmo.
