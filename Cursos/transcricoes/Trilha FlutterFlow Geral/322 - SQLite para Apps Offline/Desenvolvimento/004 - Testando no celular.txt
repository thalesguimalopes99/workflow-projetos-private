Pessoal, então bora testar a nossa aplicação num dispositivo. O que a gente vai fazer diferente agora? Ao invés de fazer pelo emulador Android, como a gente fez lá no módulo de VS Code, agora a gente vai usar o nosso próprio celular para fazer esse teste, ok? Pode ficar tranquilo que você aprendeu no módulo de VS Code, vai utilizar 95% aqui, ok? Só o último passo que é diferente. Então, vamos lá. Primeiro, você precisa ter uma versão paga do Flutter Flow, como eu já mencionei em aulas anteriores, para poder baixar o código. Então eu clico aqui, Download Code. Enquanto ele baixa, vamos entender o seguinte. Qual que é a diferença de eu usar um emulador Android e um dispositivo físico? No emulador Android, você consegue ter várias versões do sistema operacional. Você pode testar retrocompatibilidade, testar algumas features nativas. Qual que é o ponto negativo? Você está rodando um sistema operacional em cima de outro sistema operacional. E a performance, nesse caso, pode ser que seja muito ruim dependendo da tua máquina. Beleza? Agora, num dispositivo físico, qual que é a vantagem? Você tem uma performance rodando liso. Você consegue testar qualquer feature no teu dispositivo porque o processamento vem dele, ok? Não vem do teu sistema operacional emulando um outro sistema operacional. Beleza? Ponto negativo é que você está limitado à versão do seu Android atual. Mas, enfim, eu já expliquei a fazer essa versão aqui lá no módulo de VS Code. hoje a gente vai aprender a fazer dessa forma aqui. Dessa forma você tem várias maneiras de testar o teu app. E lembrando que vai ter um módulo específico de local run aqui na no-code startup. Bom, aqui baixei o meu código, vou salvar na minha área de trabalho, vou pausar o vídeo para poder extrair lá. Eu acabei de extrair o meu arquivo e abri o VS Code. Ele já abre aqui para a gente. Na sequência, eu preciso de um dispositivo para testar, certo? E aqui ele fala que eu estou sem nenhum. Então, é agora que a gente entra com o dispositivo físico. Então, para testar, eu clico aqui, vou espelhar o meu dispositivo para vocês. Na tela anterior, se eu voltar duas vezes, agora eu tenho lá embaixo opções do desenvolvedor. Na hora que eu entro, eu tenho a opção de fazer depuração USB. Ok? Pronto, agora eu consigo usar o meu celular como um emulador da minha aplicação. Agora eu só voltar para a tela inicial, vou conectar meu cabo USB. Você pode ver que meu celular está aqui. Beleza?
