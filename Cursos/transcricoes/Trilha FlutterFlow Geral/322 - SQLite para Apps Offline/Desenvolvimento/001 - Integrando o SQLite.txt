Pessoal, então como que a gente integra um banco de dados SQLite na nossa aplicação no Flutter Flow? Para fazer isso, você vai clicar aqui em configurações, depois entrar na aba integrações e clicar em SQLite. Depois é só habilitar esse botão aqui do SQLite. Ele já vai indicar alguns erros. Por quê? Ele está reclamando que você não inseriu o arquivo com extensão .db. Então, de forma bem exumida, como é que funciona o processo? A gente vai criar no nosso banco de dados uma ferramenta específica. Essa ferramenta vai gerar um arquivo .db, extensão .db. A gente vai inserir esse arquivo aqui no Flutter Flow. Depois, a gente vai configurar quais são as queries que a gente vai usar. Ou seja, quais são os comandos que a gente vai usar para vasculhar o banco de dados usando aquelas operações de CRUD, Create, Read, Update e Delete. E é isso. Tendo essa configuração, você já consegue usar o SQLite no teu app. Então, para começar, vamos criar o arquivinho em .db. Para fazer isso, você pode usar várias ferramentas como o The Beaver, outros gerenciadores de banco de dados, mas aqui eu estou usando o SQLite Browser, beleza? Nesse link você consegue acessar os downloads. Eu baixei a versão 64 bits para o Windows, que é o sistema operacional que eu estou usando. Uma vez que você baixa, a instalação é bem simples e... Ele vai criar um atalho na tua área de trabalho e você pode abrir esse programa. Ele tem essa interface, tudo limpo aqui. E para criar um banco de dados, é só clicar aqui em novo banco de dados. Depois ele pede aonde você quer salvar esse banco para o pormenário de trabalho. E ele vai se chamar apontamentos. Vou salvar. Aí ele já abre a telinha para a gente criar a nossa tabela. Lembre que banco de dados é uma coisa e a tabela é outra. A tabela está dentro do banco de dados, ok? A tabela eu também vou chamar de apontamentos. E na sequência ele pergunta quais são os campos que você quer adicionar nessa tabela. Vou clicar aqui em adicionar. Essa tabela vai ter um ID que vai ser do tipo inteiro e é uma chave primária, ou seja, a coluna que é usada para referenciar essa tabela, os itens únicos dessa tabela. Depois eu vou adicionar a coluna colaborador, vai ser um texto que eu quero o nome do cara, e depois a coluna bags, ou seja, quantos sacos de laranja aquele colaborador colheu. Beleza? também é do tipo inteiro. Você vê que tudo que eu faço aqui já é traduzido automaticamente para um comando SQL equivalente. Ok? Bom, está tudo certo? Então é só clicar em OK. Ele gera a minha tabela. Eu consigo navegar entre os dados. Ela está vazia nesse momento, mas eu posso até adicionar um aqui de exemplo. Posso falar que o colaborador Renan colheu oito bags naquele dia. Beleza. Eu também posso executar um comando SQL. Por exemplo, select all from apontamentos. Pronto, ele executou e trouxe uma única linha. Eu até cliquei nesse botão, mas poderia ser esse aqui no caso, que é a linha atual que eu estou selecionado. A hora que eu clico, ele traz esse resultado, que foi a única linha que a gente adicionou. Isso aqui é só para mostrar que a tabela está funcionando e que a gente consegue fazer operações CRUD dentro dela usando SQL. Porém, na hora de mandar lá para o Flutter Flow, eu vou mandar ela vazia. Nunca mande com uma informação, porque senão toda a Base Web App está instalada, vai vir por padrão com essa linha e a gente não quer isso. Então, eu vou clicar aqui na linha e vou deletar. Beleza? Na sequência, eu venho aqui em Escrever Modificações, Ctrl S. para ele salvar meu banco de dados. E é só isso, pessoal. O banco de dados está criado. O banco e a tabela já estão criadas. Eu poderia ter mais tabelas e fazer relacionamento entre elas. É totalmente possível. Nesse exemplo, como o foco dele é mostrar o processo, a criação, o sincronismo, a gente está usando uma tabela super simples aqui. Mas é totalmente possível trabalhar com chaves primárias e estrangeiras no SQLite. Na sequência, eu volto aqui no meu Flutter Flow e agora sim eu posso carregar o meu banco. Deixa eu clicar aqui em fazer upload, área de trabalho. Ele tem um arquivo do tipo DB, que é o meu banco de dados apontamento. Clico em abrir, ele vai carregar, e o nome do meu banco no Flutter Flow vai chamar apontamentos. Beleza. Agora, vamos ver aqui no canto, você vê que ele já parou de reclamar. Ou seja, já consegui configurar SQLite e inserir um banco de dados. Agora, a gente vai configurar as nossas queries, tanto de leitura, que seria o nosso read, e as de update, que seria... Create, Delete e o próprio Update. Ok? É isso. Mas isso é assunto para a próxima aula. Te vejo lá.
