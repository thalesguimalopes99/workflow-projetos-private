Pessoal, então bora continuar conceituando alguns pontos. Para começar, o que é o SQLite? Basicamente é um banco de dados relacional onde o SGBD, que é o sistema gerenciador do banco de dados, e o banco de dados são uma coisa só, ok? Isso deixa o banco de dados muito mais leve, você consegue trabalhar com ele de forma muito mais flexível. Como a própria definição diz, ele é projetado para ser rápido, eficiente, leve e amplamente utilizado. em vários dispositivos, inclusive aqueles que utilizam IoT, TVs, videogames, todo dispositivo que precisa de um banco de dados leve e embarcado, pode aproveitar as funcionalidades do SQLite. E você pode estar se perguntando, mas no Flutter Flow eu já usei AppState para fazer aplicações offline, qual é a diferença do AppState para SQLite? O AppState, como a própria documentação classifica e recomenda, ele é usado para operações mais simples. Imagine que você precisa armazenar qualquer escolha do usuário, se é Dark Mode, Light Mode, um carrinho de compras mais simplificado. Tudo que for mais simples, o AppState ainda resolve. Porém, quando você precisa de um banco de dados complexo, com várias tabelas, relacionamento de tabelas, consultas complexas e outra, quando você precisa fazer operações que não sejam apenas um select básico, Para isso, o AppState começa a não ser o mais adequado. Aí faz total sentido você usar o SQLite. O SQLite existe desde os anos 2000, porém no Flutter Flow ele está disponível desde fevereiro desse ano, 2024. Eles lançaram essa feature e agora está disponível para quem quiser. Então, o SQLite, como a definição diz, ele é capaz de lidar com estruturas complexas de forma eficaz. E ele é especialmente útil... quando você precisa de features offline, que é o exemplo que a gente vai utilizar aqui. Lembra que a gente vai trabalhar com uma aplicação de apontamento de colheita de laranja. Nesse caso, faz total sentido usar o SQLite. A gente pode fazer todas as operações CRUD do banco de dados, create, read, update, delete, e deixar nosso app muito mais dinâmico, coisa que com app state seria muito mais complexo, talvez travaria o app e os dados não seriam acessíveis de forma tão simples. Então, de forma bastante resumida, essa é a diferença entre o AppState e o SQLite. Agora, na sequência, vamos conhecer de fato qual é a aplicação que a gente vai trabalhar nesse módulo. Então, bora para a prática na próxima aula.
