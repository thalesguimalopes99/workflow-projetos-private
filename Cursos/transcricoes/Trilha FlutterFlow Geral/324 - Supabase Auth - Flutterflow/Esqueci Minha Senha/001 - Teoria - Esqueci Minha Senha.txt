Pessoal, então como é que funciona o fluxo do esqueci minha senha? Basicamente tudo começa com o usuário. Lá na página de login, geralmente tem um texto escrito esqueci minha senha. A hora que o usuário clica nisso, ele vai para uma página onde ele tem que informar o e-mail dele. Uma vez que o usuário informou o e-mail dele e clicou em recuperar senha, o Flutter Flow, por sua vez, ele vai enviar uma requisição do tipo post lá para a API do Superbase. Que API que é essa? A API do Password Recover. E no corpo dessa requisição, no body dela, ele vai passar o e-mail que o usuário passou na etapa anterior. Então, o usuário informou o e-mail, o Flutter Flow foi lá e fez uma chamada para o Supabase. Na sequência, o Supabase atende essa requisição e manda um link para o e-mail informado. É lógico, esse e-mail tem que ser válido. Você pode pôr algumas validações lá no teu app, por exemplo, tem arroba, algumas validações básicas, mas se o e-mail for válido, o Supabase envia para esse cara. E lá no e-mail que o Supabase manda, vai ter um link que tem que redirecionar para a página de alterar senha. Se o teu app for um app web, se for publicado na web, é uma URL. Se não, é um deep linking, ou seja, um link para você entrar em uma página específica do teu app. A gente vai ver um exemplo com deep linking já já. Na sequência, o usuário, nessa tela que ele foi redirecionado, ele informa a nova senha e clica em salvar ou atualizar o que você achar melhor do texto. Depois que o usuário faz isso, o Flutter Flow vai lá e faz uma nova requisição para o Superbase. Uma requerção do tipo put para a API, update user. Para que ele faz isso? Para atualizar a senha do usuário. Então, o e-mail ele já tem, agora ele vai lá e atualiza a senha. Uma vez que ele atualizou a senha, o Superbase registra isso de forma segura no banco de dados e o usuário pode navegar lá para a página de login. e entrar no app. Você também pode fazer com que logo que ele altere a senha, ele já entre na página inicial ou fazer com que o usuário volte para a página de login e coloque o e-mail e a nova senha dele. Tem essas duas opções. Vai do fluxo que você achar melhor. Um ponto importante. Aqui, a hora que o Subabase manda esse link para o usuário, ele encaminha um link já com um token de autenticação. Ou seja, nesse momento que ele passa o link para o usuário acessar, em tese ele já está autenticado no app. Por quê? Você confirmou que você é você mesmo através desse link que o Spabase mandou, ok? Então, em tese, se você quisesse que ao invés de ele ir para essa tela de alterar a senha, ele entrasse direto no app, seria possível também, que é o caso que a gente vai ver na sequência, do link mágico, ok? Mas, por enquanto, eu estou encaminhando o usuário para essa tela de alterar a senha, ok? Mas, se quisesse, ele já poderia entrar... no app nessa etapa aqui porque o link que o seu base manda né só reforçando já vem com um toque de autenticação Ok ele tem lá o JWT e o tempo de inspiração beleza então resumindo de forma bem simples esse é o fluxo do esqueci minha senha só que agora a gente vai ver na prática como configurar tudo isso né a gente entendeu o passo a passo mas vamos ver onde clica como é que seleciona enfim todo o passo a passo para a gente entender essa etapa beleza te vejo na próxima aula
