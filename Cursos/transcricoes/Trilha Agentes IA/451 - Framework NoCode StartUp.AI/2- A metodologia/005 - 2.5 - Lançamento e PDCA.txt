E vamos para a última etapa, que é a etapa de lançamento IPDCA, tá? Então, o que a gente vai fazer nessa etapa? Basicamente, a gente vai conseguir lançar o nosso produto aí para os nossos clientes reais, seja um projeto que a gente está fazendo, seja uma plataforma, um MVP, a gente precisa dos usuários reais, tá? O que vai validar os nossos testes, vai validar as nossas hipóteses, a gente vai descobrir pontos de melhoria, problemas que está tendo. Então, a gente precisa disso para a gente conseguir evoluir no nosso produto. É importante que você não demore tantas etapas para você conseguir testar o mais rápido possível. Beleza? E aqui a gente tem o nosso PDCA, como eu já tinha falado. A gente sempre vai estar melhorando. É um ciclo infinito de melhoria contínua. Você lança, testa, melhora, checa, age de novo. Então, o PDCA infinito. Beleza? E aqui eu coloquei um checklist, que essa etapa não tem muito segredo, basicamente é você sentir como é que está o seu mercado, como é que está o seu teste, e vai melhorando aqui, colocando o checklist de potenciais melhorias. E vai colocando também, os usuários estão pedindo essa funcionalidade, vai jogando para cima esse tipo de funcionalidade. Dessa forma a gente consegue ter aí uma gestão desse projeto. Então, basicamente aqui nessa etapa a gente consegue lançar, é claro que a gente poderia deixar mais complexo aqui, né? Como deixar realmente uma entrega de um projeto e ir fazendo a gestão, mas esse daqui é o feijão com arroz bem feito, que dá certo. Seguindo as etapas de planejamento, execução, melhoria contínua, é pra dar muito boa, tá? Geralmente é... a pessoa vai lá e faz o projeto totalmente perdido, aqui você seguindo esse framework, você já sai com uma estrutura completa para criar qualquer tipo de projeto, e não só ter o projeto, mas também se for criar um projeto com um cliente e você conseguir pegar esse framework e adaptar, entregar só isso documentado para o cliente, isso daqui já tem muito, muito valor. Geralmente ninguém faz isso no mercado, só entregam lá um agente plugado no WhatsApp, perdidão, aqui você vai entregar toda a solução. são a inteligência, tá? Isso aqui é uma consultoria já, o pessoal cobra aí 5 mil, 10 mil, 15 mil reais só pra fazer um processo de consultoria desse tipo, tá? Então você organizando esse projeto e conseguir entregar pro cliente aí, tudo documentado esse projeto, né? Claro que dá pra fazer algumas adaptações aqui, cara, isso daí já tem muito valor. E você entregando ainda um agente de A, entregando plataforma, pode ter certeza que vai longe. Mas também se você está construindo só um projeto pontual, vai seguindo aqui, algumas coisas vão se encaixar, outras nem tanto, mas vai te ajudar a criar seu projeto. Como eu falei, todas essas etapas é mais para você conhecer aqui como funciona o processo de desenvolvimento de um software, que sempre a gente vai estar criando software. E depois, em aulas futuras, a gente vai usar esse material aqui com mais calma para criar algo do zero. Então, aqui eu coloquei alguns exemplos para você ir conhecendo, mas lá na frente a gente faz um projeto do zero usando 100% esse documento. Fechou? Espero que você tenha gostado.
