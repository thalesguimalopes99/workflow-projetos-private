Agora vamos falar sobre um dos assuntos mais importantes para você que quer criar qualquer tipo de tecnologia, que é APIs. Então o que é API? API significa Application Programming Interface. Basicamente é uma interface de comunicação entre vários tipos de aplicativos. Então se você quer que seu sistema se comunique com qualquer outro sistema na internet, é por meio de API. Por isso que é tão importante. Para explicar isso a gente pode fazer a analogia do restaurante. Vamos supor que a gente tem um cliente lá no nosso restaurante. e ele faz um pedido de comida. O garçom pega esse pedido de comida, leva até a cozinha. A cozinha prepara a comida, o garçom pega de volta esse pedido de comida e leva até o cliente. Com o APIs vai ser bem parecido. O cliente vai ser o nosso front-end, a nossa interface. Então, quando tem uma inquisição lá do front-end, quem vai fazer essa comunicação entre o front e o back vai ser o nosso garçom. Então, o garçom... vai pegar esse dado aqui do cliente e vai levar até a CluSign. Então, vamos supor aqui, por exemplo, que lá no nosso aplicativo, ele coloca lá, ele vê a lista dos dados, por exemplo, ele clica no botão. Então, a API vai fazer a comunicação lá com o nosso back-end. Vai puxar lá no nosso banco de dados, a lista dos dados, e vai dar para a API de volta, mostrar quais são essas listas dos dados. Mas isso não só para o nosso back-end, como por exemplo para outros sistemas da internet. Por exemplo, lá no front-end, a gente está fazendo a comunicação com ver posts do Matheus Castello, por exemplo. Então, eu clico no botão lá no front-end, aí vai ter uma API que vai fazer uma comunicação com o sistema do LinkedIn. Então o LinkedIn vai ter uma documentação API para a gente conseguir saber como que a gente vê os posts de um determinado usuário. A gente faz uma requisição, que é basicamente um botão e vai clicar no botãozinho ali para puxar. Aí a gente vai fazer essa comunicação, a gente vai lá no LinkedIn, pede os posts do Matheus Castelo e ele vai dar os posts e a gente vai lá e traz de volta. Então, a API nada mais é que fazer essa comunicação entre o back-end, nosso sistema, mas também qualquer outro tipo de sistema da internet. Então, por que é tão importante aprender sobre APIs? Então, o que a gente consegue integrar no nosso app em qualquer outra aplicação? Se você quer integrar com um CRMX, um RPY, qualquer outro tipo de programa, ele precisa ter uma API aberta, tá bom? Então, se você quer integrar com XYZ, é possível? Se o sistema tiver a API aberta, sim, é possível. Show demais. Vamos entender agora os principais métodos da API. Então a gente consegue geralmente fazer quatro coisas principais. A primeira é o criar dados. A gente consegue criar novos dados lá nesse banco. A gente consegue visualizar dados. A gente consegue autorizar dados e conseguimos deletar dados. Esse é o famoso CRUD, que a gente fala, que é o C-R-U-D. CRUD, que é o Create, Read, Update e Delete. Então, geralmente a gente faz esses três métodos importantes. Quando a gente quer fazer, por exemplo, ler dados, a gente vai mandar um método, uma função que chama get. Get, pegar os dados. Quando a gente quer criar dados, a gente vai mandar um post de postar o dado e criar o dado lá dentro. Então, toda a interação basicamente vai ter esses quatro tipos de formas essenciais. Beleza? É importante também que você entenda a linguagem oficial das APIs, que geralmente vai ser o JSON. O JSON nada mais é que uma forma de organizar os dados que tanto a máquina entende quanto o ser humano entende também. Então, o formato leve e rápido no uso de dados, tem uma leitura simplificada para máquinas e humanos e possível criar relações complexas. Então, aqui, por exemplo, vamos supor que a gente tem um dado de usuário. Então vai ter o nome, que é basicamente um campo, idade, hobbies, endereço, rua, cidade, país. Então olha que fácil, nome, dois pontinhos, Carlos, idade, 28. Hobbies, aqui é uma lista, a gente tem uma lista de hobbies que ele tem. Então a gente consegue estruturar esses dados para ficar fácil tanto para o ser humano quanto para a máquina. Então geralmente essa vai ser a nossa comunicação, que é o Jason. Show demais!
