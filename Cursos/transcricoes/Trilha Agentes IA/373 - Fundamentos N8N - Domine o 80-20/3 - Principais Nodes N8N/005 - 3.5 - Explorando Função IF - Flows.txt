Salve! Nessa aula vamos explorar o nosso node if dos nossos fluxos. Então, vindo aqui para o N8N, nosso editor, adicionar aqui o nosso node de fluxos, vindo aqui em fluxos, encontrando aqui esse node verdinho, o if, que é uma condição C. Basicamente, essa condição C, a gente cria dois caminhos. Se tal condição é verdadeira, ele segue para o caminho verdadeiro. Se não, ele vai para o caminho falso. Então a gente constrói de maneira bem análoga o que a gente fez no nosso node de filtro, porém agora a gente tem uma saída para o node caso a condição não seja atendida. Essa é a grande diferença do node. O restante funciona de maneira bem análoga. Então entrando aqui no nosso node if, a gente pode construir as nossas condições analogamente ao que a gente fez no nosso node de filtro. Então aqui eu tenho a condição, aqui uma string, o nosso chat input, eu posso adicionar. aqui dizendo que esse campo de chat input, ele tem que ser igual, né? E aqui a gente tem a condição de string de novo, o azinho aqui, e tem que ser igual à mensagem que a gente digitou. Então nesse caso a mensagem é bom dia, por exemplo. Bom dia, se eu testar, a gente tem um bom dia aqui. É verdadeiro que a mensagem é bom dia e a gente tem aqui nosso true saindo aqui pra cima. A gente vê que tá verdinho o true aqui. Caso a mensagem seja diferente, né? Boa tarde, boa tarde. A gente vai ver que agora a gente vai para o node de false. Então a gente já vê que está verdinho aqui embaixo no false agora. Então essa é a diferença do nosso node de if. A gente tem dois caminhos. A gente consegue aqui adicionar condições tanto para string, existe, não existe, contém para números, datas, booleano, que é false, throw, false, array, objeto, assim como a gente fez no filtro. E a gente também consegue deixar... criar condições mais complexas, tanto condições E quanto condições O. Condições E, todas as condições têm que ser verdadeiras para ir para a condição true, condições O, pelo menos uma, tem que ser verdadeira. Beleza? E é importante ressaltar que nessas condições, sempre que a gente tem aqui, por exemplo, bom dia, se eu digitar o B com letra maiúscula, vou deletar esses nossos outros campos, bom dia com letra maiúscula, ele vai trazer no false, porque ele... respeita as cases, então se é letra maiúscula e respeita não entende que é igual esse bom dia. Para a gente fazer com que isso seja ignorado, a gente pode adicionar esse ignore case aqui embaixo. Agora se eu testar, ele vai para verdadeiro. Então só uma condiçãozinha a mais aí nesse nosso node de if, mas basicamente essa é a funcionalidade principal dele. Beleza? Na próxima aula a gente vai explorar o nosso node de switch.
