Fala pessoal, nessa aula bora conhecer o nosso node de switch, dos nossos nodes de fluxo. Vindo aqui para a nossa tela do computador, clicando aqui para a gente adicionar o nosso novo node, vindo aqui em fluxo, a gente tem aqui dentro agora o nosso node de switch aqui embaixo. Então clicando no nosso node de switch, nosso node de switch basicamente ele funciona muito análogo, vou pegar, só ajustar ele aqui, vou juntar aqui no nosso node do nosso input, vou aproveitar aqui também já enviar um olá, então mandar um olá e aguardar. Nosso Node de Switch funciona muito similarmente ao nosso Node de If, porém, agora a gente tem, além de apenas as opções de se for verdadeiro ou falso, a gente tem duas rotas apenas, agora a gente pode criar quantas rotas a gente quiser nesse nosso Node de Switch, dando mais flexibilidade para a gente. Então, conhecendo aqui as configurações desse nosso Node, entrando aqui no nosso Node de Switch, a gente vê que agora eu posso adicionar novas rotas, eu não tenho só apenas a rota verdadeira e falso. Colocando aqui algumas condições, então vou pegar aqui o meu chat input, vou jogar para cá. Vou falar que essa minha primeira rota, esse nosso chat input vai ser igual a Olá. A gente pode renomear essa rota. Só vou, antes de renomear, mostrar onde que isso está sendo renomeado para vocês. Então, vou adicionar mais uma rota aqui. A gente pode adicionar uma rota. Eu posso puxar esse chat input para cá também. Vou falar que esse aqui vai ser igual a Oi. Então, ele viria para esse nosso caminho, caso esse chat input fosse igual a Oi. Se eu fechar aqui e mostrar para vocês, a gente tem a rota 0 e a rota 1. Agora eu vou voltar para cá, vou renomear, falar que essa é a minha primeira rota, vai ser a Olá e a rota de baixo vai ser a minha rota Oi. Se eu voltar agora lá na frente, a gente vê que a rota 0, que era 0 agora, virou Olá e a rota de baixo virou Oi. Eu poderia novamente adicionar mais uma aqui, colocar de novo meu chat input, falar que se meu chat input for igual agora a TudoBem e renomear aqui embaixo só para ficar bonitinho, chamar TudoBem. Se for igual a TudoBem, ele viria para essa terceira rota. Então aqui, se eu testar esse meu workflow, a gente vê aqui em cima agora minha rota Olá, minha rota Oi, minha rota Tudo Bem. Eu vim aqui para a nossa rota Olá, seguindo aqui o caminho. Vindo aqui para o nosso fluxo, eu vejo que o Olá aqui está verdinho. Beleza. Então, bem direto ao ponto, o que esse nosso fluxo faz? Algumas configurações extras aqui para esse nosso Node Switch aqui embaixo. A gente tem aqui algumas opções extras. Então eu posso tanto adicionar... Um fallback output, que seria um caminho de gatilho, como se fosse um caminho de escapatória. Caso nenhum desses nossos cenários aqui de cima sejam atendidos, a gente tem um caminho de saída extra. A gente tem aqui também ignore cases, que é ignorar maiúsculos e minúsculos. Eu posso clicar aqui e deixar sim ou não. E eu também tenho a opção de enviar dados para todas as condições atendidas. Caso isso não esteja ligado, ele vai mandar basicamente apenas para a primeira condição que ele encontrar que seja atendido. Então só para vocês verem aqui, colocar um fallback, eu consigo adicionar e consigo falar o que eu quero fazer caso nenhuma das condições ali em cima seja atendido. Eu posso fazer nada, eu posso colocar um output extra, eu posso falar para ele ir para o olá, para o oi ou para o tudo bem. Então eu posso selecionar para onde ele ir. Então colocar aqui um extra, a gente pode vir aqui até agora, abre a opção para a gente renomear o... o output de fallback, e eu posso colocar aqui, por exemplo, erro. Então agora a gente vai testar aqui, eu tenho aqui agora mais um caminho, que é o nosso fallback, nosso caminho de erro. Beleza, pessoal? Com isso a gente conhece esse nosso Node de switch, que a gente vai usar bastante nos nossos workflows para a gente criar automações um pouco mais complexas. Vejo vocês aí na próxima aula.
