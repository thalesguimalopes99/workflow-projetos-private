Dando sequência no nosso case de agente de voz SDR que liga, qualifica e marca a reunião. Agora a gente vai entender uma ferramenta poderosíssima da VAP. O que são tools e como elas funcionam? Bom pessoal, o que a gente vai aprender nessa aula? A gente vai entender... o que são as tools e como servem essas mãos do agente que interage com o mundo real. Então a gente vai entender o papel das tools do Entavap e como elas conectam o agente a fontes externas como APIs, bancos de dados e automações via N8N. Então, por que a gente precisa dessas tools? Como a gente viu... lá no início do nosso case, a gente está tentando aqui fazer a orquestração entre diversos sistemas. O lead vai preencher o formulário lá no Tally, depois a gente vai gravar os dados lá no Supabase, depois a Paula vai ligar via VAP para o nosso cliente e aí, enquanto ela está na ligação, ela vai precisar consultar a disponibilidade de horários, vai precisar criar o evento e vai precisar mandar a confirmação. via mensagem para o nosso lead. Então todas essas funções que ela tem, ela precisa de um braço que conecte a VAP com o nosso N8n para lá no N8n a gente conseguir executar as ações. Então as tools servem exatamente para isso. Quando a gente precisa consultar informações, quando a gente precisa tomar ações, ou quando ele precisa se conectar com sistemas externos via API ou WebRub. Tá bom, pessoal? Então, essa funcionalidade da Tool funciona na prática da seguinte maneira. Primeiro, a gente... percebe que precisa executar uma ação então durante a conversa ali ele vai ter essa inteligência de perceber que precisa executar essa ação então ele vai acionar ato associada então por exemplo aqui né consultar a agenda a gente vai depois criar todas essas tools uma a uma aqui com bastante detalhe para não ficar nenhuma dúvida pra vocês O passo 3 é a tool enviar uma requisição para o N8N, então ele vai mandar um webhook lá para o N8N, e esse webhook vai conter todas as informações que ele precisa para que o N8N processe e retorne uma resposta. Então, depois dessa resposta enviada, a VAP vai receber a resposta e o agente vai continuar a conversa. Então, quais serão as tools que a gente vai aplicar no nosso projeto? Bom, a gente tem a nossa primeira tool que vai fazer a checagem de disponibilidade da agenda dos especialistas para a gente conseguir marcar a reunião. Depois a gente vai ter a tool de criar evento, né? Google criar evento, que ela vai fazer a criação do evento, mais o envio da mensagem no WhatsApp e mais a atualização do nosso Supabase. E para fechar, a nossa última tool é uma tool de reg. Sim, a gente vai voltar a falar de reg aqui dentro desse módulo para a gente otimizar um pouquinho o que a gente fez antes no módulo anterior.
