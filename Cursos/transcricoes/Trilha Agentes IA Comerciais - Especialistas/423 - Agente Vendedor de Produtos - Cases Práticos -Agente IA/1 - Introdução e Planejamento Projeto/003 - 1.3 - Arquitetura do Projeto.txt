Então vamos lá, nesse case desse módulo a gente vai criar um agente que atende uma loja virtual de suplementos, mas você pode usar para qualquer outro tipo de case pode ser uma loja virtual de roupas, uma loja virtual que vende produtos eletrônicos ou pode ser até um delivery que ele consegue organizar o carrinho e faz a vinda da pizza ou até um delivery de farmácia, tanto faz, a essência é a mesma então o nosso agente vai conseguir fazer duas funcionalidades muito importantes, que são elas? Primeiramente, ele vai conseguir realizar o atendimento do cliente, então ele vai atender o cliente, vai ver o que o cliente quer, vai conseguir enviar os produtos disponíveis, então o nosso agente vai até o nosso banco de dados ver os produtos disponíveis para mandar para o cliente, ele vai conseguir fazer o carrinho do cliente, então ele vai colocar os produtos que o cliente quer em uma lista, para conseguir fazer o resumo dessa lista e ver qual é o total do pedido do cliente, olha que irado. E além disso, esse agente vendedor vai conseguir realizar a venda para o cliente. Ou seja, ele vai pegar os dados completos do cliente para criar um link de pagamento com o valor total, que vai ser um link só daquele cliente. Daí a gente vai integrar com o gate de pagamento para o cliente conseguir fazer esse pagamento via Pix, via boleto ou via cartão de crédito. E sempre que você vai construir um projeto, você tem que pensar qual é a arquitetura daquele projeto. Qual é o desenho e quais são as ferramentas envolvidas. Então aqui no nosso projeto a gente tem a parte da interface da aplicação. E a gente tem a parte da inteligência, que é o back-end. Então nós temos todo o front e onde rola as automações, as integrações, o banco de dados, segurança, tudo vai ser no BACT. Além disso, a gente conecta com uma ferramenta de criação de agente de A. Aqui que vai ser consumida por um modelo de OpenAI, um modelo focado para o nosso agente e também consegue conectar em outras demais APIs. Para esse projeto a gente tem algumas ferramentas, certo? Quais são elas? Primeiro, para o front-end interface, você pode conectar no WhatsApp, no Instagram, qualquer tipo de interface que a gente já tem no TemplateMestre. A gente já ensinou isso lá no modo template master, então depois é só você conectar no whats. Aqui a gente vai focar mais no end to end, na inteligência do nosso agente. No back-end, nas automações e integrações, a gente vai usar o end to end, que é a nossa ferramenta principal aqui. No banco de dados, a gente vai focar no superbase, tá? E na criação do agente, é no próprio end to end, a gente vai usar o modelo da OpenAI. para ser consumido pelo n20 e vão precisar usar o asas tá o asas é importante para a gente conseguir trabalhar com pagamentos então você tem que usar algum guete de pagamento para conseguir trabalhar com esses tipos de pagamentos beleza combinado além disso no nosso projeto a gente tem que entender bem qual que é a arquitetura do nosso agente em si então te lembrando a gente faz quatro coisas e muito importantes que é a parte ali das instruções né a gente tem que as instruções A gente também tem aqui o modelo, a gente tem a memória, temos o reg, treinamento com dados personalizados e temos as funções para a gente conseguir conectar qualquer tipo de ferramenta da internet. Aqui nesse projeto vai ficar dessa forma aqui. O modelo LLM vamos usar o GPT, que a gente gosta bastante, mas fica aí à vontade você usar o modelo que você quiser. A memória, vamos usar a memória do Netween mesmo só para ser mais didático e rápido aqui. O reg, a gente não vai usar reg, tá? A gente usa reg em outros módulos, mas poderia ser uma ideia, por exemplo, você está criando um agente aí que ele atende uma pizzaria, você pode pegar o próprio cardápio em PDF e subir como um dado vetorial lá, para ele conseguir consumir os dados do cardápio, tá? Então, esse é um exemplo que você poderia fazer, a gente já ensinou como criar um PDF e subir no banco de dados vetorial com reg. Temos aula sobre isso. Aqui a gente vai pegar e cadastrar os nossos produtos no Supabase. Então vai ter no banco de dados os nossos produtos que fica mais estruturado e mais organizado. Show demais! Além disso, a gente vai ter algumas tools de integração. A gente tem a parte de se conectar com o Supabase para a gente conseguir ler os dados, editar dados. Também tem a parte de interação com asas, que vai ser o gate de pagamento para a gente gerar link de pagamentos personalizados. E também aqui a gente vai usar aquela calculadora, aquela função do Neto N, que ajuda aí para a nossa IA conseguir fazer cálculos e não errar ali no valor total do pedido. Então isso deve ir, é bem importante. Agora que você já entendeu nosso projeto, bora começar então com a modelagem de dados. Vamos estruturar as tabelas para a gente deixar o nosso back-end pronto para a gente poder fazer o nosso agente. Bora lá!
