Apresados no coder, sejam muito bem-vindos a mais um módulo. Módulo esse que criaremos do zero, usando o Cloud Code, o nosso aplicativo. Então a ideia aqui é que você tenha visto o módulo anterior, caso não tenha visto o módulo de Git e GitHub, e convido você a retroceder aí no curso e assistir o módulo anterior, porque todas as etapas que seguiremos daqui pra frente eu verei como base o que vimos no passado. Apesar de que o Cloud Code é um excelente copiloto, Mas é interessante que conhecemos todas as etapas do projeto e para isso convido aos que não assistirem, retrocederem e assistirem o módulo anterior de Git e GitHub. Nesse módulo atual nós construiremos um projeto, um projeto esse de gestão financeira, onde todas as transações do nosso rico e suado dinheirinho serão computadas. E teremos aí uma interface visual, uma stack profissional, onde utilizaremos muitos dos recursos atuais para que o nosso projeto seja moderno. Então, iniciaremos fazendo o PRD. O PRD nada mais é do que orientações que daremos para o nosso Cloud Code, para a construção desse projeto de gestão financeira. Nós temos aqui na NoCode já um PRD criado. Então nós temos um endereço aí hospedado, onde facilitará muito a nossa vida. Então a nossa intenção aqui é facilitar a criação dos projetos. Projeto esse que terá aí algumas etapas que chamaremos de Milestones. Dentro do desenvolvimento nós vamos preparar esse projeto para o deploy. O que é o deploy? O deploy é quando nós deixamos esse projeto preparado já para ser hospedado na internet. Então dentro da preparação desse projeto... Nós já deixaremos tudo engatilhado para o deploy. Então nós utilizaremos algumas ferramentas que estão atuais para que o nosso projeto, como eu comentei, fique moderno. Por exemplo, aqui a conexão com o Supabase. O Supabase será o nosso banco de dados, então todas as inserções que faremos dentro do aplicativo precisarão ser guardadas para que quando a gente aplique um filtro, por exemplo, semanal ou um filtro mensal... para saber o que entrou, o que saiu das nossas despesas, ele possa consultar. E para que ele possa consultar esses dados, eles deverão estar guardados dentro de um banco de dados. Esse banco de dados que utilizaremos aqui é o Superbase. Ensinarei vocês todas as etapas, todo o passo a passo do projeto. Então, nós também teremos aí uma tela de login, já que as informações são de cunho pessoal, né? Informações do destino. do nosso dinheiro, das nossas despesas. Então, para entrar nesse aplicativo, nós precisaremos de um login e uma senha. Nós deixaremos esse projeto preparado para o deploy. O deploy, como eu comentei, é quando esse projeto ganhará um endereço web. Então, você poderá acessá-lo de qualquer lugar do mundo, desde que você tenha acesso à internet. E a ferramenta que utilizaremos para fazer o deploy será a Vercel. Então, neste módulo, nós deixaremos tudo preparado, mas teremos um módulo específico de deploy, que será o próximo módulo, onde nós aprenderemos a hospedar esse nosso projeto em um endereço web. Neste módulo específico, construiremos o projeto e o prepararemos para o deploy. Utilizaremos um design moderno, dentro dos aplicativos mais recentes. O que está em alta aí é o tema escuro, claro que também poderíamos ter a opção de deixar com o tema claro, mas alguns equipamentos aí, eles economizam bateria quando utilizamos o tema escuro. E por falar em equipamentos, nosso projeto, ele será um projeto responsivo, projeto esse que poderá ser acessado do notebook, do computador, de um tablet ou do nosso próprio celular. Então, conforme o tamanho da tela que o projeto será acessado, esse nosso projeto será responsivo, ele se adaptará ao tamanho da tela e do dispositivo que usaremos para acessá-lo. Então, quando ele se adapta ao tamanho da tela, nós chamamos esse projeto de responsivo e, claro, como estaremos utilizando tudo de mais moderno do mercado, nosso aplicativo não poderia deixar de ser responsivo e o nosso Cloud Code será nosso copiloto dentro desse projeto. Vocês verão, de fato, Toda a capacidade que o Cloud Code tem para a execução desse projeto e tenho certeza que vocês ficarão surpresos aí. Nós utilizaremos aí um front-end moderno. Front-end é quando a gente acessa o projeto. Então tudo que você tem visual, todo o projeto que você consegue enxergar, esse é o front-end. O nosso back-end desse projeto será o nosso primeiro item lá, o Supabase, que é o nosso banco de dados. o nosso aplicativo ele não vê. Por isso que ele é o back-end, ele está por trás. Já o front-end utilizará ferramentas modernas e é por isso que eu conto com vocês para assistirem as próximas aulas deste módulo, onde colocaremos a mão na massa e conheceremos de fato toda a capacidade do nosso Cloud Code. Então aguardo vocês nas próximas aulas e vamos para cima.
