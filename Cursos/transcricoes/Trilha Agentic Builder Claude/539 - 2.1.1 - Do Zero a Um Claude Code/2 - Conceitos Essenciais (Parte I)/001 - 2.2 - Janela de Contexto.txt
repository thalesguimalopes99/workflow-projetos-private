Agora vamos falar sobre um conceito super importante que é a janela de contexto. Basicamente, para o Cloud conseguir trabalhar bem, você tem que dar contexto para ele. Ou seja, o que você está querendo, qual é o projeto, quais são os detalhes, o que vai ser o usuário que vai usar esse projeto, qual é a dor, qual é a solução. Quanto mais contexto... Você vai dar ali pro Cloud, melhor vai ser a entrega dele, tá? Pra isso a gente tem que entender o que é a janela de contexto Que basicamente é essa janela onde a gente consegue trabalhar com esse contexto Tem a parte boa, que ele vai entregar projetos melhores Mas tem a parte ruim Depois que você tá muito tempo conversando com o Cloud Essa janela de contexto vai ficando cheia Daí a gente tem que tomar uma ação Olha só, vamos entender, o que é a generalidade de contexto? Basicamente ela vai ser um agrupado de tudo isso daqui, vai ter a mensagem atual, então vai ter todos os tokens da mensagem atual, vai ter todos os arquivos do código, vai ter todo o histórico recente, para ele lembrar, histórico antigo, que ele vai conseguir pegar para saber qual é o contexto, vai também ter toda a parte do system prompt, que é a instrução inicial para o cloud. Então basicamente vai ser tudo que a gente manda a cada interação com o Cloud, mostrando aqui o que a gente está querendo fazer. A gente tem alguns comandos muito importantes, que são três. O clear, ele basicamente vai limpar o contexto. O compact, ele vai resumir toda aquela sua conversa, da sua sessão, e vai deixar resumida para depois o Cloud só conseguir acessar aquela parte da conversa. E o context vai mostrar o uso atual do contexto. Beleza. Então como é que funciona na prática? Então vamos supor que a gente começou a conversar com o Cloud. Então a conversa começa vazia. A gente tem aqui, vamos supor, uma barrinha do contexto de tokens. Então vamos supor que a gente tem 100 mil livres, que é a nossa janela de contexto. Quando você abre uma seção do Cloud, a janela de contexto está vazia. O Cloud ainda não sabe nada sobre você ou sobre o seu projeto. Então aqui a gente está com uma janela de contexto, com 200 mil tokens disponíveis. Então ele não sabe nada. Geralmente a gente vai carregar o primeiro documento que é o CloudMD. O CloudMD nada mais é que tem um documento que mostra o resumo do projeto, tecnologias, para o que é, qual é o objetivo. Vai ser o nosso resumo do projeto que é o CloudMD, o arquivo mais importante. Antes de qualquer mensagem sua, o CloudLer ou o CloudMD, isso já ocupa espaço na janela. Então agora ele tem contexto. Mas o contexto é essencial e garante respostas. Então ele injeta, usamos aqui 8% do contexto. Daí vai começar a conversa. Você tem a sua pergunta, tem o arquivo lido, o Cloud tem a sua resposta, arquivo gerado. Então tem essa troca, essa comunicação com o Cloud que a gente está gerando no nosso projeto. Basicamente, essa janela de contexto vai enchendo aqui, já está em 42%. E a cada mensagem sua, o Cloud vai acumulando contexto. Só que chega um momento... Que aí fica urgente aqui, que quando fica muito cheio o Adminar de Contexto, o Cloud começa a esquecer o início da conversa e aí a qualidade da entrega cai. Então isso aqui é muito importante, porque quando tem muito contexto na mesma sessão, a gente precisa abrir uma sessão nova. Então o que a gente vai fazer? Basicamente você vai ter que ou limpar o contexto. fazer um barra clear, ele vai limpar todo o contexto, ou vai fazer o barra compact, basicamente ele vai resumir o contexto e vai deixar ali preparado para depois para uma nova conversa. E aí vai resumir, finalizar a sessão e começar uma sessão nova para a gente conseguir voltar com a qualidade aqui do Cloud em relação às suas entregas. Então basicamente é isso que serve a agenda de contexto, você tem que trabalhar o contexto de uma forma estruturada, que ele é parte boa, é que a gente tem que passar contexto para o Cloud entregar. mas também a gente tem que compactar cada sessão usando o compact para ter entregas melhores. Depois a gente vai ver na prática também mais conceitos super importantes para você lembrar na hora do seu desenvolvimento.
