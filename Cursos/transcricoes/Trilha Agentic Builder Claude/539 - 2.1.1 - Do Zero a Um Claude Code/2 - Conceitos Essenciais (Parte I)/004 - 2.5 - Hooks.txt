Agora vamos falar sobre um conceito importante que são os hooks. O que são hooks no Cloud Code? Basicamente vão ser gatilhos automáticos. Então quando a gente configurar, quando o Cloud Code fizer X, execute Y automaticamente. Basicamente é um hook. Quando tal coisa acontecer, ele vai seguir por tal caminho. Sem precisar pedir, sem depender do cloud para nem fazer, acontece sempre de forma garantida. O HOOKING é muito importante porque dessa forma a gente consegue garantir alguns padrões. Quando a gente trabalha com A, A é não determinístico, ou seja, cada vez que a gente vai fazer algo, ela pode tomar ações diferentes para executar e ter um output diferente. Dessa forma, quando você precisa seguir aquele padrão exato, você precisa dizer que quando acontece isso... Faça isso. E realmente seja direto ao ponto, aí o hook é uma boa prática. Então, como é que funciona? A gente pede para o Cloud, por exemplo, edita esse arquivo. Aí, quando você fala isso, a gente vai ter um hook, por exemplo, que vai falar... Pre-to-use. O hook dispara. Então ele vai antes executar, ele pode bloquear ou aprovar. Ele vai executar a ação e depois a gente pode ter um outro hook. Depois de executar, ele formata o código automaticamente. Ou seja, dependendo do processo, dependendo do projeto que você está construindo, o hook vai disparar aí quando você precisar. Legal, alguns exemplos aqui da própria documentação do Cloud, que a gente pode usar RUC, a gente pode ter uma notificação sempre que o Cloud precisa de você. Então quando o Cloud termina uma tarefa e fica esperando, você pode receber uma notificação no desktop, pode trabalhar em outra coisa sem ficar olhando o terminal. Esse é um exemplo. Ou também o Cloud pode formatar um código automaticamente após edição. Então toda vez que o cláudio edita um arquivo, a gente pode rodar um hook automaticamente e esse código sempre sai formatado sem você pedir. Então a gente pode, por exemplo, fazer um hook de um agente que ele vai automatizar a parte de revisar o seu código, por exemplo. Então vai depender do que a gente quer. ali no hook. A gente também pode bloquear edições em arquivos protegidos. Então, se o Cloud tentar mexer no Envy, que é onde tem as nossas chaves API e alguns arquivos mais sensíveis, o hook pode bloquear. Isso daqui é uma das partes mais importantes do uso do hook. Ou também rejeitar contexto após compactação. Quando a memória do Cloud enche e esquece as coisas, um hook injeta automaticamente as informações importantes de volta. Esse daqui são só alguns exemplos sobre como utilizar a hook. A gente vai usar em outros projetos no futuro, mas é um conceito importante para você deixar anotado aí e lembrar quando a gente voltar a falar sobre hooks no Cloud Code. Beleza?
