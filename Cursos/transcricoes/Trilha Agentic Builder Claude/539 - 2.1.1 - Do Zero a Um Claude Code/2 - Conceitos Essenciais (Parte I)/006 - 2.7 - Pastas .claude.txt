Um assunto muito importante é sobre as pastas que a gente tem nos projetos do cloud. A gente vai ter uma pasta que é por projeto e também a gente vai ter pastas globais que só você vai usar. Vamos entender a diferença entre essas duas. Primeiro é a pasta .cloud. Essa pasta aqui vai ser uma pasta por projeto. Então se você estiver trabalhando em um projeto, vai ter uma pasta cloud dentro daquele projeto. Ela vai guardar tudo que é específico daquele repositório. A gente vai comitar, ou seja, a gente vai salvar... todas as atualizações e a gente vai mandar lá para a nuvem no Git quando a gente for atualizar, porque é uma pasta importante para você salvar, manter o versionamento e para a sua equipe também ter acesso. Geralmente vai ter a pasta aqui no projeto, aqui tem algumas outras pastas que a gente tem, umas genéricas, e aqui vai ter a pasta do Cloud, vai ter configurações que é desse projeto. Então a gente pode criar agentes e sub-agentes para esse projeto, pode ter comandos só para esse projeto. Pode ter a parte aqui do setting JSON, que é as permissões e preferências para esse projeto. Então, a pasta .cloud é a pasta por projeto. Ela só vai contar dentro desse projeto. Porém, a gente também tem a pasta aqui, que vai ser o cloud da sua home. É uma pasta da sua home do seu sistema operacional. Ela vai guardar configurações pessoais suas, que vão valer para tudo. Você não comita, você não vai jogar para a nuvem lá no GitHub, porque é só seu. Você vai ter a sua pasta cloud, ela geralmente vai ficar escondida lá nos seus arquivos, mas ela vai estar lá na sua home. Então vai ter suas configurações globais. O jeito que você conversa, o jeito que você pensa, a parte de memória, os seus sub-agents pessoais que você consegue ativar. Você consegue também as suas instruções globais aqui nessa pasta. E também as suas preferências globais de permissionamento. Então, essa pasta aqui é só para você. Então, a gente tem essas duas. Para a gente entender aqui um resumo da diferença entre essas duas, a gente tem a .cloud, que é dentro do seu projeto. E temos a cloud aqui com... Contigo, né? Na sua home global. Aqui vai ter o CloudMedia também, que é só para o projeto. Vai ter o Settings de um JSON, que é as permissões só para o projeto. Os agentes só para esse projeto. As Skills e os comandos só para esse projeto. MCP JSON só para esse projeto. E aqui a gente vai ter o Settings e o Cloud local, que vai ser para esse projeto, tá? Além disso, a gente vai ter aqui a pasta do Cloud para tudo, né? Que é a sua pasta global. Então você consegue ter seus próprios agentes pessoais, você consegue ter suas skills pessoais, que podem valer para tudo, se quiser trabalhar com elas. Vai ter as suas memórias, atualizações pessoais, estão tudo aqui. O que está em cinza é o que geralmente a gente vai comitar lá para o GitHub e salvar no versionamento.
