Seja muito bem-vindo ao módulo de Skills. Aqui você vai aprender tudo sobre Skills e como a gente usa no ecossistema do Cloud. A gente vai ver os fundamentos, o passo a passo para você instalar a Skill, para você conseguir fazer uma Skill do zero e também vamos fazer alguns cases práticos que sejam úteis no dia a dia da sua empresa ou da sua rotina profissional. Beleza, vamos entender primeiro o que são Skills. Basicamente, a Skill é um arquivo, uma pastinha, que ela ensina o Cloud a trabalhar do seu jeito. Em vez de explicar tudo a cada conversa nova, você escreve isso uma vez e o Cloud passa a seguir automaticamente. É como dar um manual completo para o assistente no primeiro dia. Então basicamente o Skill vai ser uma automação ou habilidade, como o Cloud chama. Se você tem algo que você repete todo dia que você está fazendo, seja criar uma planilha PDF, criar um dashboard, ou subir um processo aqui no meu caso, subir vídeos de YouTube, subir conteúdos, a gente consegue automatizar e as Skills fazem isso de uma forma muito bem feita e você não precisa ter o background técnico então basicamente é uma forma da gente conseguir padronizar esse processo passa pro cloud e toda vez a gente ativa o cloud que a gente quer fazer isso e ele faz de uma forma com maestria basicamente uma skill ela vai ser uma pastinha então basicamente a gente vai ter uma pastinha Lá no nosso computador, tá? Que a gente pode subir na nuvem ou deixar no computador. Mas vai ser uma pasta com vários arquivos. O mais importante é o Skill MD. O MD, lembra que é de Markdown, né? Basicamente, aqui vai ser um manual de instrução da Skill. Então, vai estar escrito aí o que a Skill faz, como que ela é ativada, vai ter as regras, quando usar, exemplos. Aqui, ó, vai ser o documento mais importante das Skills. Além disso, a gente tem outro tipo de documentos. A gente tem a pasta também. Referências, aqui a gente tem materiais complementares, então a gente tem PDFs, planilhas, imagens, tudo que vai ajudar a gente conseguir automatizar aquela tarefa. Beleza. Também temos scripts, aqui são códigos e funções ou chamadas APIs, então quando a gente tem alguma automação, pode ser em algum códigozinho ali para rodar, vai ser tudo guardado aqui. Aqui você não precisa se preocupar, tudo o Cloud vai fazer, tá? E temos asets também, que são os templates, fontes e ícones para utilizar. Então basicamente você tem que pensar que se você faz algo repetitivo dia a dia, você consegue automatizar, organizar, e o Cloud vai organizar tudo nessa pastinha, para quando a gente pedir para ele fazer, ele já vai fazer aqui automaticamente. Beleza, vamos entender aqui, para que serve? Vai servir para padronizar e automatizar os processos. para dar apoio no desenvolvimento de projetos e também para compartilhar com a equipe. Se você quer padronizar alguma atividade que você faz e deixar tudo estruturado, faz de uma vez e depois você consegue padronizar com o seu time. Vamos mostrar alguns exemplos aqui.
