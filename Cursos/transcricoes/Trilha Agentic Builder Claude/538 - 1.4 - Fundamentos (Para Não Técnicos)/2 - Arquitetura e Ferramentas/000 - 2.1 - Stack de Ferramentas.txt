Agora vamos falar um pouco sobre as principais ferramentas que a gente vai usar para criar nossos projetos aqui dentro da formação, tá? Separei aqui algumas das principais, depois vão ter outras que a gente vai conectando à medida da demanda que a gente for tendo aí dos projetos, tá? Muito importante, para a parte de orquestração, orquestração nada mais é que a gente conseguir orquestrar os agentes para construir nossos projetos, tá? Aqui, por exemplo, a gente vai ter o Cloud Code. que é uma plataforma de um agente que está orquestrando outros agentes. Então, se a gente quer criar softwares, aplicativos, a gente vai usar o Cloud Code, mas também se a gente for criar automações, áreas inteiras, a gente vai usar toda a orquestração lá dentro do Cloud Code, que é uma ferramenta excepcional. Depois, lá sobre o Cloud Code, a gente vai falar mais sobre ele. Aqui, vamos usar também uma interface que é o cursor. Basicamente, é uma IDE. Para quem não sabe o que é IDE, é uma interface de... desenvolvimento para gente. Por exemplo, a gente poderia usar o Code Code direto no terminal, que é aquela tela preta, a gente pode usar no aplicativo lá, ou a gente pode usar na IDE. Deixa eu mostrar aqui para você como é que funciona. Aqui, por exemplo, a gente tem o VS Code. O VS Code é uma IDE, nada mais é que é um lugar que a gente consegue ir conversando com o nosso IA, mas também acessar arquivos, conseguir... editar arquivos, tá? Não precisa ficar preocupado aqui com a parte dos códigos, a gente não precisa saber nada disso. O que a gente precisa saber é gerenciar o nosso agente lá do Cloud Code ou do Open Cloud, né, que a gente estiver fazendo. Então a gente consegue utilizar o Visual Code Visual Studio pra isso, mas também gostamos bastante do cursor, tá? O cursor, ele tem toda essa interface, ele é uma ideia, mas ele também tem o agente dele por trás. Então a gente gosta dele e basicamente a gente usa uma união. da ideia do cursor com o agente do Cloud Code. Então essa aqui é uma forma da gente conseguir utilizar ambas as ferramentas. Além disso, para criar front-ends, interfaces e back-end, a gente vai usar algumas ferramentas que a gente gosta bastante. Primeiro é o Next.js, que é basicamente um framework, um conjunto de ferramentas, um pacote de funcionalidades para a gente construir nossos projetos. Junto com o ChatCN, que vai ser uma biblioteca de bons modelos e estruturas para a gente usar nos nossos projetos. Já vou mostrar. Em conjunto com o Supabase. O Supabase nada mais é que um back-end, onde vai ter banco de dados, vai ter toda a parte de segurança, autenticação. Então, tudo a gente vai conseguir criar lá pelo Supabase. Bem importante. Então, aqui, entrando no site do NextGS, explica. um pouco mais, né, o que é esse React Framework, pra que serve, então um framework pra gente construir projetos aí bem robustos, tá, quando a gente tá falando de software, a gente geralmente vai adotar isso que a gente vai fazer em aulas práticas mais pra frente, tá, e o Chatcene, basicamente, é uma biblioteca de componentes, tá, bem legal também, que deixa todo o nosso app com a interface bem melhor. E o Supabase, como eu falei, é um back-end, pra gente fazer toda a parte de banco de dados, então a gente consegue ver aqui, ó, Tem toda a gestão dos dados, a gente consegue ter autenticação, que é a segurança, consegue ter funções aqui também, consegue gravar arquivos, PDFs, utilizar bancos de dados vetoriais para IA. Então, acaba sendo uma excelente ferramenta para a gente fazer o back-end, como eu tinha falado. É a parte inteligência, a parte automação, a parte aqui de segurança, a gente consegue conectar pelo back-end. Beleza. E além disso, tem algumas outras ferramentas interessantes também, quando a gente está falando de criação de projetos, mais específico de software. Tem a parte de versionamento, que basicamente a gente vai controlar as versões do nosso projeto. Vamos ter uma aula aqui sobre isso daqui a pouco, então eu não vou me estender, tá? Mas a gente vai ter o versionamento local, que é o nosso computador, e o versionamento lá na nuvem, que vai ser o GitHub, tá? E além disso, a gente vai ter deploy, que é basicamente colocar em produção. Em projetos com o Next.js que a gente vai construir, a gente vai usar a ferramenta Verticell para colocar em produção. Em alguns projetos, a gente consegue utilizar de uma forma mais facilitada a parte da Hostinger, da VPS. Então, a gente vai abordar um pouco das duas ao longo da formação e outras que virem melhorando. E aí tem a parte de APIs. Se a gente quer mandar um e-mail, geralmente a gente vai usar resend. Quando você coloca lá, esqueci minha senha, tem que ter uma integração de e-mail. Então vai ser o Recend. Ou outras ferramentas, por exemplo, Stripe, para pagamentos, mas poderíamos usar o SaaS. Então aí tem várias e várias ferramentas que a gente consegue conectar via API ou via MCP. Mas basicamente isso daqui é um desenho geral das ferramentas que a gente vai usar. Algumas outras vão ser mais específicas para os outros tipos de projetos, mas quando a gente estiver criando um app, uma plataforma, um software, a gente vai usar essas ferramentas aqui.
