Bora falar agora sobre APIs e MCPs que são conceitos bem importantes para você construir seus projetos, tá? Como eu tinha falado, API nada mais é que quando a gente faz algo ali no nosso projeto para ele se comunicar com outra ferramenta do mercado. Então se você quer colocar pagamentos no seu app, você tem que ter uma API de pagamentos que a gente vai usar lá. Então a gente consegue usar a API do Stripe, API do Asus. Você colocar a forma de enviar e-mails, então a gente vai usar a API do Recend, que envia e-mails. Então toda vez que você quer conectar com uma outra tecnologia, a gente usa a API. Basicamente a gente vai fazer uma conexão entre o seu app e esse projeto. Coloquei aqui um desenho para ficar um pouco mais claro, a metáfora mais simples é da cozinha. O que a gente tem aqui, você faz o pedido, o pedido aqui quem vai levar é a API, que é o garçom, leva até a cozinha, o servidor, tá? Então isso daqui pode ser tanto o nosso servidor quanto o servidor de outras plataformas. Tem a resposta e volta aqui e a API entrega a resposta para a gente. Então a gente não entra na cozinha, o garçom que é a API vai levar e trazer para a gente. Basicamente a API vai ser o garçom que vai ficar levando e trazendo aí dados, tá? Por que elas são importantes? A gente não precisa entender o interior, a gente só realmente faz uma requisição dessa API lá para os pagamentos e volta se a pessoa, por exemplo, pagou ou não, ou se a gente quer um link de pagamento. A gente consegue conectar tudo, aplicativos, dados, serviços, e a gente poupa tempo. Ao invés de criar algo do zero, a gente já usa um serviço que já existe. Isso daqui é muito importante sobre APIs. Então, alguns exemplos. Tem o Stripe para pagamentos, a gente pode fazer uma API para processar pagamentos. pessoa está pagando assinatura, para gerar um Pix para ela, por exemplo, o Asas ou o Pagar.me. A gente consegue ter também a API de localização para usar todo o Google Maps e os mapas. A gente consegue usar a própria API de IA, usar a própria LLM de um cloud ou de um chat de PT para a gente usar. toda a inteligência ali. Pode ter API para WhatsApp, para a gente conseguir conectar o nosso serviço, o nosso agente lá no WhatsApp. A gente tem que usar uma API de WhatsApp. Então, basicamente, como que a gente usa na prática? A gente vai ter que fazer uma conta, né? Nessa empresa, nessa plataforma que a gente quer usar, fazer uma chave e aí, a partir dessa chave, chamar um endpoint, né? Um endpoint, basicamente, é o endereço que a gente quer mandar a nossa requisição. E daí, a API, ela traz um JSON. Basicamente isso é um formato que vem escrito todos os dados. Então, por exemplo, no Stripe eu quero saber se o usuário pagou. Daí eu mando uma requisição perguntando se aquele usuário pagou boleto ou não. E daí o Stripe vai mandar de volta falando, ó, esse usuário está com boleto pago ou não está. Se não tiver, a gente, por exemplo, pode cortar o acesso dele. Daqui é bem importante você entender sobre APIs, tá? Vamos ter vários exemplos práticos depois. Também é bom você entender o MCP, que ele significa Model Context Protocol. Basicamente, é um formato padrão que as empresas e softwares estão desenvolvendo para fazer as IAs conseguirem comunicar com seus projetos. Então, como que é sem MCP? Então você, o dev, o seu app, você tem que ir lá conectar com a API do Slack, ou ir lá conectar com a API do Notion, ou ir lá conectar com a API do GitHub. Então cada API vai ter uma documentação diferente, um formato diferente, docs diferentes, você faz tudo do zero. O MCP nada mais é que ele é um padrão para deixar tudo isso mais fácil e a gente conseguir criar nossos projetos com a. Ele realmente muda bastante a fluidez que é feito nos nossos projetos. Com o MCP, a gente, por exemplo, pode ter o Gmail, o GitHub, o Google, e ele vai todo no MCP ali, que ele vai conseguir padronizar essa aquisição e conseguir ver as mensagens, o integrar. A gente, basicamente, é uma forma de comunicação oficial. que facilita muito para a IA conseguir interagir com aquela tecnologia, tá? Na prática, o que muda? A gente tinha o servidor MCP, que a gente consegue conectar qualquer outro projeto, a gente tem uma ação autônoma, então o call de águia a gente não só responde e ele é bem customizável, tá? A API, a gente vai conseguir integrar. Já o MCP é feito para a EA conseguir usar. Então a gente vai acabar usando muitos MCPs dentro dos projetos. Porque a gente consegue ganhar muita agilidade e robustez nas operações. Então só para ficar um pouco mais claro para você. O que é a PEI e o que são MCPs são conceitos bem importantes.
