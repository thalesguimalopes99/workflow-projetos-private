Fala aí turma, sejam bem-vindos para mais uma aula e nessa aula a gente vai estar falando sobre Book Operations, tá? São operações em massa ali, você vai no banco de dados e você pode selecionar uma ação e utilizar ela para fazer de uma única vez ali um gatilho manual ali, digamos que você precisa alterar uma determinada quantidade de dados, você pode utilizar o Book Operations para realizar essa ação. Para utilizar o Book Operations a gente vai precisar primeiramente criar um API workflow, tá? É bem simples, a gente vai adicionar um API Flow da maneira que a gente sempre fez antes. Então adiciona um API Flow. Vamos dar o nome para ele de Book Operation aqui. Vou só colocar o nome certinho ali. Para vocês encontrarem depois no app de teste. Aqui, Book Operation. Ok. Vamos ignorar as privacidades. E vamos adicionar um parâmetro. O parâmetro vai ser histórico. Vamos alterar o histórico das nossas ações, dos nossos projetos, das nossas tarefas. Vamos selecionar o type aqui como histórico. Ok? Se eu estou como histórico. Não vou adicionar mais nada e não pode ser lista, tá? Esse dado aqui tem que ser um único dado mesmo, ok? Vamos selecionar aqui o make change. E eu já criei uma coluna chamada de id histórico, tá? Deixa eu vir aqui, ID histórico. Eu vou calcular a fórmula. Vai ser um Arrange Stringer, tá? Com 10 caracteres. Somente Numbers. Pronto. A gente já tem a nossa ação que vai rodar no Book. Ok? Vemos aqui no banco de dados. E eu tenho aqui a minha coluna de ID histórico. Se eu dar um refresh, ela não tem nada aqui. Não tem nada criado. Mas eu vou vir aqui no book. Percebam que tem outros API workflows. Mas eles são de listas. E esses workflows de listas. Não podem ser rodados aqui. Nessa opção em massa. Percebam que aqui a gente tem o book. O que a gente criou. Ele vai rodar em 18 itens. Que é exatamente o número de itens que a gente tem no nosso banco de dados. Então vamos selecionar a opção. Aqui, book operation. E a gente vai dar um workflow. Ok. Ele já realizou a ação e vai trazer o status aqui, ó, Book Operation Room Sucesso em 18 itens. Então, foi bem sucedido em 18 itens. E se a gente vir e der um refresh aqui, a gente já atribuiu um ID ao histórico. Isso pode ser para deletar, adicionar, alterar, diversas ações. Você pode utilizar o Book Operation para realizar, tá? De forma mais manual ali e algo mais rápido. Digamos que você... Queria enviar esses dados e não tinha um ID porque você criou anteriormente e adicionou a coluna ID recentemente.
