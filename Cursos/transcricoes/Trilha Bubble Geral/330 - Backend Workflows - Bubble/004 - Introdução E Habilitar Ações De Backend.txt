Fala aí turma, sejam bem-vindos para mais uma aula e nessa aula eu vou ensinar para vocês como ativar as ações de Backend Workflow lá no Bubble. Turma, estando aqui no painel do editor aqui, né, do nosso aplicativo, onde a gente quer ativar o nosso Backend Workflow, o que a gente tem que notar primeiro é, vem aqui onde a gente troca de page, né, onde a gente troca as páginas, tá? Vai vir aqui e vai conferir se já não tem o nome aqui Backend Workflow, de repente você comprou um template, ou algo do tipo, já pode vir em ativo aqui, Backend Workflow. Geralmente fica aqui abaixo, né, do reutilizável, ok? Vai ter o nome aqui, Backend Workflow. Pra ativar é muito simples. A gente vai aqui em configuração, né, em settings. Geralmente a gente vem aqui, ó. Já sai aqui, né, quando a gente clica em settings. Vocês vão vir no menu superior e vai procurar por API. Clicou em API, a gente tem aqui, ó, public API endpoint, tá? Aqui a gente ativa os endpoints do banco de dados para a gente poder puxar e criar itens dentro do nosso banco de dados aqui no Bubble, tá? Mas a gente também consegue dar enable ao API Workflow. A gente tem aqui, ó, enable, né? Enable Workflow API e end backend workflow. Então a gente vai ativar as APIs, ok? Nosso workflow ali do banco de dados, ok? E a gente já ativou o back-end, ok? A gente pode também ativar a API, ok? E aqui a gente já consegue fazer buscas também no banco de dados ali, através desse link. A gente não vai entrar nesse termo aqui, mas através desse link você consegue puxar, por exemplo, a lista de projetos, ok? Coloca ali no API Connector, essa URL, substitui object por projetos, pelo nome projetos, e dá um get ali que você vai entender como que busca essas informações aqui. Ok? Tendo o nosso Backend Workflow ativado, a gente vai vir aqui em Page novamente e vai estar aqui, Backend Workflow. Clicando aqui dentro, a gente já consegue visualizar as informações do Backend Workflow e adicionar steps nesse Backend. Na próxima aula, eu vou estar ensinando vocês como criar ali um API Workflow e agendar para alteração de um único item.
