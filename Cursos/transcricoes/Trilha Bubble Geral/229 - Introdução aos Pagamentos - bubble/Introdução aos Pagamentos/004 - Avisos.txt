Antes da gente partir para as nossas próximas aulas, nosso curso aí, começar a colocar a mão na massa, criar o nosso carrinho de compra, nossas ordens e começar... a integrar com os meios de pagamento, tem alguns avisos iniciais. Tenho dois avisos rapidinhos para vocês. Primeiro aviso, nosso foco aqui dessa trilha dos pagamentos é ensinar vocês a criar o carrinho de compras, criar uma ordem de compras, entender como que a gente estruturou todo o banco de dados, todas as lógicas para fazer isso da melhor forma possível. E nosso objetivo é ensinar vocês a integrar com os melhores meios de pagamento do mercado. Então a gente vai pegar esse nosso aplicativo e vai integrar com esses meios de pagamento, seja para fazer um pagamento avulso, seja para fazer uma... assinatura. Porém, o objetivo dessa trilha não é te ensinar a criar o design dessa loja, como que a gente fez ali cada elemento. A gente já tem a trilha de fundamentos para te ensinar a usar todos os elementos, a criar tudo do zero, todo elemento do zero. A gente tem a trilha de design e responsividade, onde a gente vai a fundo nessa parte de design, deixar elementos responsivos, utilizar todas as features de design que a gente tem. aí dentro do Bubble. Então esse é o meu primeiro recadinho para assim de fato a gente focar no qual é o objetivo de cada uma das trilhas de cada um dos conteúdos. Assim vocês conseguem ir nos conteúdos, assistir eles quando vocês precisarem de fato daquele conteúdo e o que eu vou estar passando naquele conteúdo é de fato aquilo. Aqui eu não vou ficar delongando para quem quer aprender o seu pagamento, só ficar falando sobre design aqui que não é o foco.
