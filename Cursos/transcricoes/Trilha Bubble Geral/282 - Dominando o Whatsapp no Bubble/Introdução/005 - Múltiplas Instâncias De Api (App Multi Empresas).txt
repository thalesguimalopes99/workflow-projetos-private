Fala aí turma, sejam bem-vindos para mais uma aula e nessa aula eu vou apresentar para vocês apenas a API multi-instância, uma API que a gente conecta vários números ali, a gente consegue ter várias sessões com números diferentes, ou seja, você pode oferecer um serviço de chatbot, um serviço de conversas integradas ali ao seu sistema, apenas utilizando uma API com multi-instância, que vários usuários podem entrar e se conectar ao seu servidor utilizando o WhatsApp dessa pessoa, no caso, né? Por exemplo, eu tenho o meu WhatsApp, eu posso ir lá escanear o QR Code, e gerar uma conexão no seu sistema. Digamos que o seu amigo pode entrar no seu sistema e gerar também uma conexão e ter o WhatsApp dele e o seu conectado. E quando os usuários interagirem, a interação será com o WhatsApp de cada usuário de acordo com aquela conexão. Então, vou mostrar para vocês na prática como funciona e nas próximas aulas vou estar ensinando também sobre essa integração. Aqui no nosso painel modi-seção, a gente consegue ver que eu já tenho um número conectado, que é o meu número já do meu WhatsApp aqui. Eu já conectei ele, escaneei o QR Code e ele já está conectado. Inclusive, eu consegui trazer a foto do meu WhatsApp, trazer aqui o status que está conectado e eu trouxe também o nome que está lá no meu WhatsApp, tá bom? Então, esse nome aqui é o que está salvando o meu WhatsApp, naquela partezinha que a gente coloca o nome e a minha foto. Se eu enviar a mensagem aqui, eu vou conseguir enviar a mensagem através do meu número, ok? Então, aqui eu posso enviar um teste. Lembrando que eu vou enviar a mensagem para mim mesmo, tá? Esse número aqui é o meu. Vou enviar. E a mensagem foi enviada com sucesso. Vamos olhar lá no WhatsApp. Aqui no WhatsApp a gente já pode ver que a gente tem aqui a mensagem de teste, tá? Tem outras mensagens de teste aqui que a gente estava fazendo nas últimas gravações. E aqui a gente tem a mensagem que eu acabei de enviar. Inclusive eu posso voltar aqui na API Multistância e posso enviar a API Multistância. Só para a gente poder realizar o testinho, só para vocês verem aqui realmente. Aguarda um segundinho aqui. E a mensagem chegou para a gente automaticamente. E no painel multisessão, a gente consegue trocar o usuário logado e a gente vai ver que a conexão é por usuário, aqui no caso. Eu estou com o user logado e ele está conectado. Se eu vir aqui no meu banco de dados e eu logar com o user 2, ele vai aparecer como desconectado porque o usuário não está conectado ali, ele não gerou a sessão. Deixa eu logar aqui novamente. Vamos no logo. Beleza, agora ele vai logar e vai mostrar para mim que o usuário não está conectado, que a sessão é inexistente, ou seja, eu preciso conectar o WhatsApp. Então eu posso vir aqui e escanear o QR Code. Pronto, o QR Code foi gerado, eu posso escanear e gerar uma nova conexão com outro número, uma outra seção, uma outra opção de conexão aí para o seu usuário. Na próxima aula eu vou estar falando um pouco mais sobre a API da Meta, a API oficial de WhatsApp da Meta.
