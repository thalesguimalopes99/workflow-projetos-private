Fala aí turma, sejam bem-vindos para mais um aula e nessa aula a gente vai estar fazendo uma comparação entre o plugin List of Datas com o plugin Full Calendary. Vou estar mostrando para vocês a diferença entre cada um deles e os pontos de benefício. Falando já do plugin List of Datas, ele é um plugin que permite a gente criar diversos tipos de calendário, diversos tipos de lista de datas da forma que a gente desejar. Então a gente pode criar até um próprio full calendário utilizando o plugin List of Datas. Um exemplo bem prático, por exemplo, é o nosso app de agendamento aqui, onde eu tenho uma lista de datas separadas da lista de horários. A gente consegue customizar o formato, a forma que os horários estão distribuídos. A gente consegue trazer listas para dentro dessas próprias listas aqui. Tomando cuidado com os workloads, é claro. Então a gente consegue ter, por exemplo, as listas de datas de forma que a gente... possa definir tanto o layout, a quantidade de dias, quando vai começar, quando vai terminar, qual o formato de fonte, qual a cor, a gente consegue deixar totalmente dinâmico, então a gente consegue ser mais fiel a um design, por exemplo. Ok? Então, se você for ver uma referência, digamos que você pegou uma referência de calendário, você vai conseguir reproduzir essa referência totalmente com o List of Dater, tá? O plugin de calendário aqui, basicamente. Não de calendário, de lista de datas, né? Exatamente. Com esse plugin, você vai conseguir reproduzir isso. Qual que é o ponto negativo?
