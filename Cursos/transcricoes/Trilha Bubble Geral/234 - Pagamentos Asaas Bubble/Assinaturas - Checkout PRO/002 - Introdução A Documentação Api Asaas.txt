Agora eu vou estar mostrando para vocês a documentação do Asus para a gente poder realizar a integração do Checkout Pro. A gente precisa de apenas dois endpoints, que é o endpoint de criar cliente e de criar assinatura. Esse endpoint a gente vai possibilitar a criação de um cliente lá no Asus e vincular esse cliente ao nosso aplicativo Bubble. Vincular ali o cliente que está criado no nosso aplicativo, criar ele também lá no banco para a gente identificar quem é quem. O outro endpoint a gente pode criar uma assinatura para esse cliente em específico. e retornar um link no qual a gente vai ser levado para um checkout, que é próprio do Asus ali. Eu vou estar mostrando esses endpoints lá na documentação para vocês poderem localizar eles lá, e-mails, outros endpoints, e ver qual que a gente vai estar utilizando. Quando vocês abrirem a documentação da API do Asus, vocês vão ver essa primeira tela, que é o comércio por aqui. Aqui vocês vão encontrar a URL do ambiente produção e do ambiente sandbox, assim como... as URLs para criar a conta de teste, que é a conta de sandbox aqui. Então vocês podem clicar aqui para criar a conta. Tem uma conta de teste. Vocês vão criar nesse ambiente aqui, que é o ambiente sandbox. Ele é totalmente de teste. Se a gente vir aqui embaixo, a gente tem a URL que vai ser utilizada no endpoint, que é barra sandbox.asas.com barra API barra o nome do endpoint que a gente vai utilizar. E para encontrar o endpoint que a gente precisa, A API é totalmente organizada por tópicos. Então, a gente tem cobranças, clientes, notificações, parcelamentos, assinaturas, Pix e assim por diante. Os endpoints que a gente precisa, quais? Cliente e assinatura. Então, a gente vai aqui na parte de clientes e a gente tem aqui criar um novo cliente. Esse é o endpoint que a gente vai utilizar. Tem outros endpoints também, como listar cliente, recuperar um cliente, atualizar um cliente. Só que o endpoint que vai estar utilizando é o endpoint de criar novo cliente. Ok? A gente vai precisar também do endpoint de assinatura, criar uma nova assinatura. Então, se a gente clicar em assinaturas, vai ser o primeiro endpoint. Tanto em cliente, é o primeiro endpoint, criar novo cliente, quanto em assinatura, criar uma nova assinatura. Na próxima aula, eu vou estar mostrando para vocês como montar essa chamada aqui, pegar o JSON e levar lá para o API Connector e criar a chamada diretamente no nosso aplicativo.
