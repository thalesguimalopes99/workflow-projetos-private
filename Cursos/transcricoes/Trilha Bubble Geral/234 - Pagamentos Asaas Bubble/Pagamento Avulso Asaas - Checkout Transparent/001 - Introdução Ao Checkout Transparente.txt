Fala aí pessoal, sejam bem-vindos para mais um módulo. Nesse módulo a gente vai estar aprendendo a realizar a integração do Asas com o Bubble, utilizando o checkout transparente, que é aquele checkout que o usuário preenche os dados do cartão diretamente na nossa aplicação. Aqui no editor a gente já tem os campos onde a gente vai popular com as informações do cartão para realizar a cobrança diretamente no nosso app, sem precisar fazer igual ao checkout próprio, que é levar o usuário para uma página do próprio Asas. Na próxima aula a gente vai estar aprendendo como montar a chamada na documentação.
