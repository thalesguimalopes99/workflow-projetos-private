Fala pessoal, tudo bem? Hoje a gente vai introduzir vocês ao módulo de APIs. Então a gente vai tratar aqui o que são as APIs. Também vamos construir algumas aplicações para a gente fazer de modo prático. Então, nesse primeiro momento eu quero introduzir vocês às APIs. O que são as APIs? Pessoal, eu gosto de utilizar essa analogia que nosso colega Neto da NoCode Startup também utiliza bastante. Então, o que são as APIs? A gente vai fazer uma analogia de cliente, garçom e cozinha, tá? Então, a gente vai simular que o cliente é nosso front-end, é nosso website, é nosso aplicativo, tá? Ele vai fazer um pedido ao garçom e o garçom vai até a cozinha e vai trazer de volta para o cliente esse pedido, tá? Então, o que representa a API aqui? Nesse caso, o nosso garçom, tá? O nosso garçom é a API. Então, o nosso front-end... ali do aplicativo do website. A gente faz um pedido ao garçom, que é a API, e a API vai buscar lá no server, lá no database, o que o cliente pediu. As APIs funcionam dessa seguinte forma. Então, por exemplo, a API serve para a gente integrar, por exemplo, com o WhatsApp. Então, a gente pode fazer um chatbot, pode criar ali um clone do WhatsApp Web, fazer esses pedidos e eles fornecerem para a gente ali coisas que o sistema deles tem e a gente não tem. Ou, por exemplo, quando a gente integra algo com a inteligência artificial, com o OpenAI, por exemplo, e a gente faz uma solicitação via nosso aplicativo e o OpenAI ali, o chat GPT traz para a gente de volta. Então, a API é a gente poder integrar com sistemas terceiros. Então, a gente consegue integrar com outros sistemas, fazer solicitações a esses sistemas que eles trazem para a gente de volta de acordo com a nossa lógica e com o que a gente configurou. Então, pessoal, qual que é os tipos de operações que a gente consegue fazer com a API? A gente já viu ali nos outros módulos, quando a gente trabalhou com o Iweb e Xeno, a gente já estava fazendo operações de API, porque o Xeno é um back-end, porém um sistema diferente do Iweb. Então, para a gente se conectar e fazer as solicitações para o Xeno, a gente precisa ser pela API, pelo endpoint. Então, quais são os métodos que a gente pode fazer? via API, a gente pode fazer um post, né, que é criar um novo dado, criar uma solicitação, a gente pode fazer um get também, que é visualizar os dados, ou seja, você vai trazer ali os recordes, os registros, vai poder trazer um registro só, ou vários registros de algo, você pode fazer um put, né, ou patch, que é o update, ou seja, você vai atualizar dados, né, então você vai fazer mudanças ali no server, no database ali. De acordo com a necessidade. E a gente também tem aí a parte de delete, tá? De deletar dados. Então, pessoal, essa é a introdução às APIs, tá? A gente vai colocar a mão na massa. Então, a gente vai colocar o nome do super-herói ali e vai trazer ali os dados do super-herói. E a última, a gente vai fazer uma integração ali. com o chat GBT, tá?
