Olá, nessa aula nós vamos aprender o que são e como criar views no Subpabase. O que são e como criar views no Subpabase? O que é uma view? Uma view é uma tabela virtual. Ela está baseada numa consulta SQL. A view, ela não armazena os dados fisicamente. Ela apenas apresenta os dados de outras tabelas de forma personalizada. Ou seja, lá no nosso backend nós temos as tabelas que guardam as informações e as views são consultas pré-definidas que vão estar ali prontas para mostrar as informações. Então eu trouxe aqui um exemplo para a gente detalhar bem o que pode compor uma view. Olha só, aqui eu tenho... uma tabela que está me mostrando, isso daqui é o resultado de uma suposta view, então eu tenho aqui, olha, dados da tabela de clientes, eu tenho aqui dados da tabela de pedidos, tenho dados da tabela de detalhes pedidos, tenho dados aqui da tabela de produtos, e eu consigo calcular um dado aqui dentro de uma view, então a view, olha só, eu tenho... é condições de trazer os dados de várias tabelas em um só lugar. Através dos relacionamentos que nós criamos entre as tabelas, o SQL consegue agrupar para a gente aqui dessa forma, de forma organizada, e consegue até fazer cálculos. Então, a importância de entender o conceito. A tabela guarda a informação, a tabela não calcula, ela não faz... mais nada, ela só está guardando ali onde ela está encarregada por absorver ali o peso dos dados, guardar aqueles dados. Em contrapartida, a View é um mecanismo que vai nos auxiliar a agrupar, a ordenar, a calcular, a visualizar as informações de forma inteligente. É como se você, quem usa Excel, tem ali várias planilhas. e faz ali uma tabela dinâmica, tem uma visualização pré-definida e tudo mais. Então, vamos aqui para a tela do UPA Base.
